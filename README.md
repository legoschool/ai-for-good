## 학생에게 보여 줄 때

둘러보기 쪽을 교실 화면에 띄우면 열두 활동이 그림 카드로 펼쳐집니다.
카드마다 **체험해 보기** 가 있어 방 코드 없이도 활동을 눌러 볼 수 있습니다.
혼자 체험한 내용은 그 기기에만 남고 학급 기록으로 올라가지 않습니다.

## 수업 하루 전 5분

1. 사이트에서 그날 차시 페이지를 엽니다.
2. **지도안 보기** 를 눌러 화면에서 읽습니다. 내려받지 않아도 됩니다.
3. **활동지 보기** 를 열고 인쇄하기를 눌러 학급 수만큼 뽑습니다.
4. **수업 슬라이드** 를 열어 좌우 화살표로 한 번 넘겨 봅니다.
5. 웹앱을 열어 **혼자 체험해 보기**로 학생이 볼 화면을 미리 봅니다.

## 수업 슬라이드 쓰는 법

파워포인트를 열지 않고 브라우저에서 바로 넘깁니다. 파일을 옮길 필요가 없습니다.

| 하고 싶은 것 | 이렇게 합니다 |
|---|---|
| 다음 장 | 오른쪽 화살표, 스페이스, 화면 오른쪽 클릭 |
| 앞 장 | 왼쪽 화살표, 화면 왼쪽 클릭 |
| 예상 답변 보기 | 아래 **예상 답변 보기** 또는 `N` 키. 학생에게는 숨겨 두고 필요할 때만 켭니다 |
| 전체 화면 | **전체 화면** 또는 `F` 키 |
| 종이로 뽑기 | **인쇄** 를 누르면 모든 장이 한 장씩 인쇄됩니다 |
| 태블릿 | 좌우로 밀어서 넘깁니다 |

지도안과 활동지도 같은 방식입니다. 화면에서 읽고, 필요할 때 **인쇄하기** 를 눌러 종이로 뽑습니다.
한글 파일로 고쳐 쓰고 싶으면 차시 페이지 아래 **파일로 내려받기** 를 씁니다.

## 한글 파일에 무엇이 들어 있나

내려받는 `.hwpx` 도 화면과 같은 내용입니다. 표 안에 발문과 예상 답변이 그대로 들어 있고,
표 뒤에 아래 아홉 가지가 이어집니다.

학습 목표 · 시간 배분(0분부터 40분까지) · 판서 계획 · 웹앱 운영과 방 만들기 ·
평가 기준(잘함, 보통, 도움 필요) · 자주 나오는 어려움과 대처 여섯 가지 ·
지도 유의점과 개인정보 지도 · 기기가 없을 때 · 산출물과 교육과정

활동지에는 오늘의 약속, 오늘 할 일 체크, 칸마다 그 차시의 실제 발문, 쓰는 줄 다섯,
스스로 점검 다섯 문항, 오늘 새로 알게 된 것이 들어 있습니다.

첫 시간 전에는 **[사전 설문](../out/webapp/common/index.html)** 을 한 번 돌립니다.
12차시가 끝난 뒤 같은 앱에서 사후를 고르면 변화량이 자동으로 계산됩니다.

## 수업 중 웹앱 쓰는 법

```
선생님 화면 → 새 방 만들기 → 6자리 코드가 뜸 → 복사 버튼으로 복사
→ 칠판이나 화면에 코드 띄우기
→ 학생은 코드 + 비밀번호 4자리 + 닉네임으로 입장
→ 활동 → 제출하기
→ 선생님 화면에서 제출 현황과 집계가 3초마다 갱신됨
→ 결과 크게 띄우기 로 학급 이야기 나누기
→ 수업이 끝나면 방 잠그기
```

- **닉네임만 씁니다.** 실명, 학번, 연락처, 사진은 넣지 않습니다.
- 교사 화면을 닫아도 방은 사라지지 않습니다. 코드만 알면 다시 열 수 있습니다.
- 같은 닉네임으로 다시 들어와 고쳐서 제출해도 됩니다. 마지막 제출이 반영됩니다.
- **CSV 내려받기** 로 그 방의 기록을 표로 저장할 수 있습니다.

### 기기가 부족할 때

전 차시에 대안이 있습니다. 모둠에 한 대만 있으면 모둠 대표가 입력하고,
한 대도 없으면 교사 시연 화면과 인쇄 카드(`out/교구/`)로 같은 활동을 합니다.
활동지만으로도 차시가 완결되도록 만들었습니다.

## 12차시 흐름

세 모듈이 발견에서 판단으로, 판단에서 실천으로 이어집니다.
**판단 활동은 반드시 직접 겪은 경험 뒤에 옵니다.** 경험 없는 윤리 토론은 규범 암기가 되기 때문입니다.

### 모듈1 발견 (1~4차시) · AI를 직접 만들고 겪어 본다

| 차시 | 학습 주제 | 웹앱에서 하는 일 |
|---|---|---|
| 1 | AI는 어떻게 똑똑해질까 | 카드에 이름표를 붙여 분류기를 학습시키고, 데이터를 줄여 정확도가 무너지는 것을 본다 |
| 2 | AI도 틀린다, 환각과 검증 | 미리 넣어 둔 답변을 검증 3단계로 확인하며 환각을 찾아낸다 |
| 3 | AI도 편견을 가질까 | 직업 그림 12장을 뽑아 치우침을 세어 보고, 데이터를 고르게 바꿔 다시 뽑는다 |
| 4 | 내 정보는 안전할까 | 카드 24장을 한 장씩 판단하고 확신도를 남긴 뒤 개인 리포트를 받는다 |

### 모듈2 판단 (5~8차시) · 우리의 기준을 세운다

| 차시 | 학습 주제 | 웹앱에서 하는 일 |
|---|---|---|
| 5 | 보조자일까, 대행자일까 | 생각 축과 결과물 축으로 장면을 배치하고 경계 사례에 조건을 붙인다 |
| 6 | AI 신호등 판단 놀이 | 1차 판정 → 학급 분포 확인 → 2차 판정. 바꾼 판단이 그대로 남는다 |
| 7 | 우리 반 AI 약속 만들기 | 금지형 문장을 화면이 잡아 준다. 조건형으로 고쳐 쓰고 1인 3표로 투표한다 |
| 8 | 우리 반 AI 약속 선포식 | 약속 카드를 화면에서 만들고, AI 활용 표기 없이는 제출되지 않는다 |

### 모듈3 실천 (9~12차시) · 기준대로 살아 본다

| 차시 | 학습 주제 | 웹앱에서 하는 일 |
|---|---|---|
| 9 | 생각을 먼저, AI는 그다음 | 1단계를 다섯 문장 쓰기 전에는 2단계가 열리지 않는다. 처음 글과 다시 쓴 글을 견준다 |
| 10 | AI에 기대도 괜찮을까 | 익명 자가 점검 뒤 네 영역 개인 리포트를 받고 약속 세 가지를 만든다 |
| 11 | AI for Good 프로젝트(1) | 누가 언제 무엇 때문에를 채우면 문제 정의가 한 문장으로 조립된다 |
| 12 | AI for Good 프로젝트(2) | 발표 카드를 만들고 서로에게 배운 점을 남긴다. 첫 시간 생각과 지금 생각을 견준다 |

## 수업 중에 생기는 일

| 이런 일이 생기면 | 이렇게 합니다 |
|---|---|
| 학생 화면이 비어 있다 | 학교망에서 막힌 것이 아닙니다. 외부 참조가 없는 단일 파일입니다. 새로고침을 먼저 해 봅니다 |
| 인터넷이 끊겼다 | 쓰던 내용은 그 기기에 남습니다. 연결이 돌아온 뒤 다시 제출하면 됩니다 |
| 방 코드를 잃어버렸다 | 선생님 화면 → 기존 방 열기 → 코드를 넣으면 다시 열립니다 |
| 같은 닉네임이 두 명이다 | 막지 않습니다. 뒤에 낸 제출이 반영되므로 닉네임 뒤에 숫자를 붙이게 합니다 |
| 결과가 안 보인다 | 3초마다 갱신됩니다. 새로고침 버튼을 눌러 봅니다 |
| 화면을 크게 보고 싶다 | 선생님 화면의 **결과 크게 띄우기** 를 누릅니다 |
