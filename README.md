## 12차시 구성

세 모듈이 발견에서 판단으로, 판단에서 실천으로 이어집니다.
**판단 활동은 반드시 직접 겪은 경험 뒤에 옵니다.** 경험 없는 윤리 토론은 규범 암기가 되기 때문입니다.

### 모듈1 WISE 발견 (1~4차시) · AI를 직접 만들고 겪어 본다

| 차시 | 학습 주제 | 웹앱 |
|---|---|---|
| 1 | AI는 어떻게 똑똑해질까 | 데이터 실험실 |
| 2 | AI도 틀린다, 환각과 검증 | AI 검증 실험실 |
| 3 | AI도 편견을 가질까 | 편향 관찰 갤러리 |
| 4 | 내 정보는 안전할까 | 정보 분류 카드 |

### 모듈2 WISE 판단 (5~8차시) · 우리의 기준을 세운다

| 차시 | 학습 주제 | 웹앱 |
|---|---|---|
| 5 | 보조자일까, 대행자일까 | 보조·대행 분류판 |
| 6 | AI 신호등 판단 놀이 | AI 신호등 판정단 |
| 7 | 우리 반 AI 약속 만들기 | 우리 반 AI 약속 |
| 8 | 우리 반 AI 약속 선포식 | 약속 선포 게시판 |

### 모듈3 WISE 실천 (9~12차시) · 기준대로 살아 본다

| 차시 | 학습 주제 | 웹앱 |

## 설계 원리

| 원리 | 내용 |
|---|---|
| 생각 먼저 | 모든 차시에 `내 생각 먼저 → AI 검토 → 내 말로 재구성` 3단계를 넣습니다 |
| 겪고 나서 판단 | 판단·약속 활동(모듈2)은 직접 겪은 경험(모듈1) 뒤에 옵니다 |
| 금지 목록이 아니라 판단 기준 | 우리 반 AI 약속은 "하지 말 것"이 아니라 "어떤 조건이면 되는가"를 담습니다 |
| 모두가 참여하는 설계 | 1인 1기기가 없어도 참여할 수 있는 대안을 **전 차시에** 마련했습니다 |
| 클릭만으로 전개 | 발문, 예상 답변, 도구, 체크리스트를 지도안에 모두 적었습니다 |

### AI 신호등 4단계 (6차시)

| 신호 | 정책 용어 | 학생 언어 |
|---|---|---|
| 초록불 | 기본 활용 가능 | 그냥 써도 돼 |
| 노란불 | 조건부 활용 가능 | 조건을 지키면 돼 |
| 주황불 | 제한적 활용 | 아주 조심해서만 |
| 빨간불 | 활용 금지 | 쓰면 안 돼 |

## 웹앱

12차시 웹앱과 공통 설문 앱 **13개가 완전히 같은 골격**을 씁니다. 활동 화면만 차시마다 다릅니다.

```
교사가 방 만들기 → 6자리 숫자 코드 + 복사 버튼
→ 학생이 코드 · 비밀번호 4자리 · 닉네임으로 입장
→ 활동 (여기만 다름) → 제출
→ Firebase 저장 + Google Sheets 백업
→ 교사 화면에서 제출 현황 · 집계 · CSV 내려받기 · 방 잠그기
```

- **단일 HTML 파일**입니다. 외부 CDN을 참조하지 않아 학교망에서 차단되지 않습니다.
- Google Sites `삽입 → 소스 코드 삽입` 에 그대로 붙여 넣을 수 있습니다.
- 방 코드 없이 들어가는 **혼자 체험** 경로가 있습니다.
- **실명·학번·연락처를 수집하지 않습니다.** 닉네임만 씁니다.
- 앱마다 [제작 프롬프트](out/webapp/L06/PROMPT.md)를 함께 두었습니다. 각자 고쳐 만드실 수 있습니다.

### 쓰기 전에 해야 할 설정

1. Firebase 콘솔 → Realtime Database → 규칙에 [`spec/firebase_rules.json`](spec/firebase_rules.json) 의 `wise` 블록을 넣습니다.
2. 백업 시트 → 확장 프로그램 → Apps Script 에 [`spec/07_웹앱_공통사양.md`](spec/07_웹앱_공통사양.md) 4-3절 코드를 붙이고 웹 앱으로 배포합니다.
3. 배포 URL을 `build/make_webapp.py` 의 `SHEET_ENDPOINT` 에 넣고 `py -3 build/make_webapp.py all` 을 다시 돌립니다.

## 다시 만들기

`data/lessons.json` 이 **단일 진실 원천**입니다. 지도안·활동지·PPT·웹앱·사이트가 전부 이 파일 하나에서 나옵니다.

**산출물을 직접 고치지 않습니다.** json을 고치고 다시 만듭니다.

```bash
py -3 build/validate_data.py            # 먼저 통과시킨다

py -3 build/make_lesson_hwpx.py all     # 지도안 12편
py -3 build/make_worksheet_hwpx.py all  # 활동지 12종
py -3 build/make_ppt.py all             # PPT 12세트
py -3 build/make_webapp.py all          # 웹앱 12개 + 공통 설문
py -3 build/make_docs.py all            # 진도표 · 카드 교구 · 해설서
py -3 build/make_site.py                # 통합 웹사이트

py -3 build/verify_all.py               # 82개 검사 한 번에
```

필요한 것 : Python 3.12 (`python-pptx`, `openpyxl`, `lxml`), Node.js
