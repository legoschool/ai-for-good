# 구글 시트에 기록을 쌓는 법 (한 번만 하면 된다)

`wise_sheet.gs` 를 시트에 붙여 넣고 배포하면 아래가 자동으로 된다.

- 학생이 제출하면 **차시별 탭**과 `제출_통합` 탭에 한 줄씩 쌓인다.
- 설문은 문항이 컬럼으로 펼쳐진 `설문` 탭에 쌓인다. 영역 점수도 함께 계산된다.
- 교사가 방을 만들면 `방목록` 탭에 남는다. 관리자 화면이 이것을 읽어 전체 학급을 본다.

기록 설계의 근거는 `spec/20_기록과_효과성_측정.md` 에 있다.

---

## 1. 붙여 넣기

1. 기록용 시트를 연다.
   https://docs.google.com/spreadsheets/d/1szLUD-hzMwQh7aaae5S9S7OS-hEXMEMj2Vhbd-hjjFM/edit
2. 메뉴에서 **확장 프로그램 → Apps Script** 를 연다.
3. 편집기에 있던 코드를 **전부 지우고** `build/apps_script/wise_sheet.gs` 의 내용을 그대로 붙여 넣는다.
4. 저장한다. 프로젝트 이름은 아무렇게나 두어도 된다.

## 2. 탭 만들기 (한 번만)

1. 편집기 위쪽 함수 목록에서 **`setup`** 을 고른다.
2. **실행** 을 누른다. 처음에는 권한 승인 창이 뜬다. 본인 계정으로 허용한다.
3. 시트로 돌아가면 탭이 생겨 있다.
   `방목록` `설문` `제출_통합` `L01` ~ `L12`

이미 있는 탭은 건드리지 않는다. 다시 실행해도 자료가 지워지지 않는다.

## 3. 배포하기

1. 편집기 오른쪽 위 **배포 → 새 배포** 를 누른다.
2. 유형은 **웹 앱** 을 고른다.
3. **실행 사용자 : 나**, **액세스 권한 : 모든 사용자** 로 둔다.
   학생 브라우저에서 익명으로 호출하므로 이 설정이 아니면 기록이 쌓이지 않는다.
4. 배포하면 `https://script.google.com/macros/s/.../exec` 주소가 나온다. 복사한다.

## 4. 주소를 하네스에 넣고 다시 만들기

```bash
cd "8. WISE 산출물/harness"
echo "복사한 주소" > data/sheet_endpoint.txt
py -3 build/make_webapp.py all
py -3 build/make_admin.py
py -3 build/make_site.py
```

주소가 바뀌지 않았다면 이 단계는 건너뛴다. 이미 넣어 둔 주소가 있다.

## 5. 되는지 확인하기

- 웹앱에서 **선생님 화면 → 새 방 만들기** 를 누른다. 시트 `방목록` 에 한 줄이 생긴다.
- 학생 경로로 들어가 제출한다. `제출_통합` 과 그 차시 탭에 한 줄씩 생긴다.
- 관리자 화면(`admin.html`)에서 **시트에서 전체 학급 불러오기** 를 누른다.
  방 목록이 뜨면 `doGet` 까지 제대로 배포된 것이다.

## 6. 자주 막히는 곳

| 증상 | 까닭과 해결 |
|---|---|
| 관리자 화면이 "시트를 읽지 못했습니다" | 배포 접근 권한이 **모든 사용자** 가 아니다. 다시 배포한다 |
| 시트에 아무것도 안 쌓인다 | 코드를 바꾸고 **새 배포** 를 하지 않았다. 배포 주소가 옛 코드를 가리킨다 |
| 제출은 되는데 차시 탭만 비어 있다 | `APP_TO_LESSON` 의 slug 가 `lessons.json` 과 다르다 |
| 시각이 이상하다 | `stamp()` 가 서울 시간으로 찍는다. 시트 서식이 텍스트인지 확인한다 |

## 7. 시트 정리 도구 (사람이 직접 실행한다)

`wise_sheet.gs` 안에 함수 세 개가 들어 있다. 시트 편집기에서 함수를 골라 **실행**을 누른다.
웹앱은 이 함수들을 부르지 않는다. 수업 중에는 쓸 일이 없다.

| 함수 | 하는 일 | 언제 |
|---|---|---|
| `점검하기` | 탭마다 행 수, 사람 수, 똑같이 겹친 행 수를 **보여만 준다** | 먼저 이것부터 돌린다 |
| `겹친행지우기` | **시각까지 똑같은 행**만 지운다 | 같은 제출이 여러 번 들어갔을 때 |
| `최신만남기기` | 방·닉네임마다 (설문은 사전·사후마다) **마지막 제출만** 남긴다 | 학생이 고쳐서 다시 낸 것을 하나로 정리할 때 |

**지우기 전에 `파일 > 사본 만들기` 로 사본을 떠 둔다.** 되돌릴 수 없다.

## 8. 개인정보

시트에는 **닉네임, 학생이 정한 숫자 네 자리, 응답**만 쌓인다.
실명·학교·학년·반·연락처는 어디에도 들어가지 않는다.
학년도가 끝나면 학급 단위 통계만 남기고 개별 행을 지운다.
