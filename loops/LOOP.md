# loops/LOOP.md — 실행 루프 정의

한 바퀴가 작업 하나다. 작업 하나는 **차시 1개 × 산출물 1종**이다.

```
① 선택 ② 적재 ③ 생성 ④ 자가검증 ⑤ 자동검증 ⑥ 수리 ⑦ 기록
```

---

## ① 선택

```bash
python3 build/next_task.py
```

스크립트가 선행 관계를 보고 **작업 하나**를 골라 준다. 직접 고르지 않는다.

출력에는 아래가 들어 있다.

- 작업 ID와 산출 경로
- 읽을 프롬프트 파일
- 읽을 규격 절
- 읽을 데이터 (해당 차시 객체 하나)
- 체크리스트 파일
- 자동 검증 명령

막힘이 하나라도 있으면 새 작업을 내주지 않는다. 사람이 결정해야 한다.

---

## ② 적재

```bash
python3 build/update_state.py "<작업ID>" 진행
```

`next_task.py`가 알려 준 파일**만** 읽는다.

- `data/lessons.json`은 **해당 차시 객체 하나만** 읽는다.
- 12차시 전체를 컨텍스트에 올리지 않는다.
- 다른 차시의 산출물을 참고용으로 열지 않는다. 문체가 섞인다.

---

## ③ 생성

만들기 전에 **계획을 3~6줄로 쓴다.** 무엇을 어떤 구조로 만들지 적는다.

그다음 산출물을 만든다. 프롬프트 파일이 형식을 지정한다.

---

## ④ 자가검증

체크리스트를 **한 항목씩 실제로 확인하며** 채운다.

- 확인하지 않고 `[x]`를 채우지 않는다.
- "아마 맞을 것"은 실패로 본다.
- 항목마다 어디서 확인했는지 한 줄로 적는다.

---

## ⑤ 자동검증

`next_task.py`가 알려 준 명령을 그대로 실행한다.

```bash
python3 build/validate_data.py
python3 build/validate_hwpx.py out/지도안/WISE_L03_지도안.hwpx
python3 build/validate_pptx.py out/ppt/WISE_L03_수업.pptx
node build/smoke_webapp.js out/webapp/L03
node build/check_site.js out/site
```

---

## ⑥ 수리

실패하면 **원인을 한 줄로 진단한 뒤** 고친다.

- 수리는 **최대 3회**다.
- 3회를 넘기면 멈춘다.

```bash
python3 build/update_state.py "<작업ID>" 막힘 "사유"
```

금지 사항이다.

- 검증을 건너뛰는 것
- 체크리스트 항목을 고쳐서 통과시키는 것
- 요구사항을 낮추는 것
- 검증 스크립트를 느슨하게 고치는 것

이 규칙이 없으면 모델은 검증을 우회하는 쪽으로 흐른다.

---

## ⑦ 기록

```bash
python3 build/update_state.py "<작업ID>" 완료 "비고"
```

`STATE.md`의 상태·완료일·진행률이 갱신되고 다음 작업이 출력된다.

사람이 무언가를 결정해 주면 반드시 기록한다.

```bash
python3 build/update_state.py --decision "질문" "결정" "반영 위치"
```

---

## 보고 형식

작업 하나를 끝낼 때마다 멈추고 **3줄로 보고**한 뒤 다음으로 넘어갈지 묻는다.

```
- 만든 것 : (작업 ID와 산출 경로)
- 검증 결과 : (통과한 명령과 결과 한 줄)
- 다음 작업 : (next_task.py 가 내준 다음 작업)
```

사람이 "이 형식으로 나머지 진행"이라고 승인하면 **같은 산출물 종류에 한해** 연속 처리해도 된다.
이때도 차시마다 자동 검증과 상태 기록은 개별로 한다.

---

## 차시 안의 순서

이 순서를 어길 수 없다. `next_task.py`가 막는다.

```
지도안 → 활동지 → PPT → 웹앱 구성안 → 웹앱 프롬프트 → 웹앱 구현 → 사이트 차시 페이지
```

앞 산출물이 뒤 산출물의 입력이기 때문이다.
지도안의 발문이 PPT 발표자 노트가 되고, 웹앱 구성안이 프롬프트의 입력이 된다.

## 차시를 넘는 순서

- 웹앱 모음 허브(`out/site/apps.html`)는 **12개 웹앱 구현이 모두 끝나야** 착수한다.
- 웹사이트 구현은 **디자인 시안이 끝나야** 착수한다.
- 사이트 차시 페이지는 해당 차시의 앞 6종이 끝나야 착수한다.
