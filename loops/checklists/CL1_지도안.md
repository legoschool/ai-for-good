# CL1. 지도안 완료 정의

작업 : `L<NN>/지도안` · 산출 : `out/지도안/WISE_L<NN>_지도안.hwpx`

확인하지 않고 `[x]` 를 채우지 않는다. "아마 맞을 것"은 실패로 본다.

## 파일
- [ ] `assets/base_지도안.hwpx` 를 복사해 제자리 수정했다. 빈 상태에서 새로 조립하지 않았다.
- [ ] `mimetype` 이 zip 첫 항목이고 무압축(STORED)이다.
- [ ] 고친 문단의 `linesegarray` 를 전부 지웠다.
- [ ] `py -3 build/validate_hwpx.py` 가 OK 를 냈다.

## 내용
- [ ] 학습 주제와 학습 문제가 `lessons.json` 과 글자 그대로 같다.
- [ ] 도입 5분 · 전개 30분 · 정리 5분 구조가 살아 있다.
- [ ] 전개 활동이 2개 이상이다.
- [ ] 교사 발문마다 예상 답변이 최소 1개 있다.
- [ ] 중점 휴먼스킬 2개의 지식·이해 / 과정·기능 / 가치·태도가 모두 있다.
- [ ] 준비물 부호 `☆` `★` `△` 가 각각 최소 1번 나온다.
- [ ] 이 차시의 웹앱 이름이 정확하다. 옛 표기(웹앱1·2·3)가 없다.
- [ ] 다른 차시의 학습 문제가 섞여 있지 않다.

## 표기
- [ ] em dash(—)를 쓰지 않았다.
- [ ] 옛 3단계 신호등 표현(허용·조건부·제한)이 없다.
- [ ] 교사용 문장은 평서형, 학생 발문은 청유형이다.
