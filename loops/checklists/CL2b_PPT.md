# CL2b. PPT 완료 정의

작업 : `L<NN>/PPT` · 산출 : `out/ppt/WISE_L<NN>_수업.pptx`

## 파일
- [ ] 16:9 (13.333in × 7.5in) 이다.
- [ ] 슬라이드가 10~16장이다.
- [ ] 모든 텍스트에 `맑은 고딕` 폰트를 지정했다. 지정하지 않으면 교사 PC에서 깨진다.
- [ ] `py -3 build/validate_pptx.py` 가 OK 를 냈다.

## 내용
- [ ] 표지에 차시 번호·모듈·학습 주제가 있다.
- [ ] 학습 문제 슬라이드가 따로 있다.
- [ ] 전개 활동마다 슬라이드가 하나씩 있다.
- [ ] 웹앱 안내 슬라이드에 앱 이름과 화면 목록이 있다.
- [ ] AI 미사용 대안 활동 슬라이드가 있다.
- [ ] 오늘의 배움 슬라이드에 지식·이해 문장이 있다.
- [ ] 저작권 표기가 있다.

## 발표자 노트
- [ ] **빈 노트가 하나도 없다.**
- [ ] 지도안의 교사 발문이 노트에 전부 들어갔다.
- [ ] 예상 답변도 함께 들어갔다.
- [ ] 준비물과 유의점이 해당 슬라이드 노트에 있다.

## 표기
- [ ] 슬라이드 본문은 요약이다. 지도안 문장을 통째로 붙이지 않았다.
- [ ] em dash(—)를 쓰지 않았다.
