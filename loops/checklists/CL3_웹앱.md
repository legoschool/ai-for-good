# CL3. 웹앱 구현 완료 정의

작업 : `L<NN>/웹앱 구현` · 산출 : `out/webapp/L<NN>/index.html`

`spec/09_웹앱_결함목록.md` 의 실제로 터졌던 10건이 이 목록의 뿌리다.

## 단일 파일
- [ ] HTML 하나로 끝난다. CSS·JS 를 전부 인라인했다.
- [ ] 외부 CDN·폰트·이미지를 참조하지 않는다. 학교망에서 차단된다.
- [ ] Google Sites 소스 코드 삽입에 그대로 붙일 수 있다.

## 실제로 터졌던 것
- [ ] 방 코드 옆에 **복사 버튼**이 있고, `navigator.clipboard` 실패 시 대체 경로가 있다.
- [ ] 교사가 화면을 닫아도 방이 사라지지 않는다. 방 상태는 서버에 있다.
- [ ] **닉네임 중복을 막지 않는다.** 같은 닉네임이면 기존 기록을 이어받는다.
- [ ] 방 코드 없이 들어가는 **혼자 체험** 경로가 있고, 서버에 쓰지 않는다.
- [ ] 정규식에 `\d` `\s` `\w` 를 쓰지 않았다. `[0-9]` 등으로 썼다.
- [ ] 페이지 body 가 가로로 스크롤되지 않는다. 넓은 표는 자체 스크롤 상자에 있다.
- [ ] `window.top` 접근, 새 창 열기, `alert` 남용이 없다.
- [ ] 빈 상태로 제출하면 막고 무엇이 빠졌는지 알려 준다.
- [ ] 저장 실패 시 학생 화면이 멈추지 않고 안내 문구가 뜬다.
- [ ] Sheets 백업 실패가 학생 화면을 막지 않는다.

## 저장
- [ ] Firebase 경로가 `/wise/<slug>/<방코드>/` 아래로 격리돼 있다.
- [ ] 레코드에 `nick` `group` `app` `room` `at` `payload` 6개 키가 있다.
- [ ] Sheets 백업이 `no-cors` + `text/plain` 으로 나간다.
- [ ] `getAnalytics` 를 붙이지 않았다.

## 교사 화면
- [ ] 새 방 만들기, 제출 현황, 집계, CSV 내려받기, 방 잠그기가 있다.
- [ ] 3초 폴링으로 갱신된다. SSE 를 쓰지 않았다.

## 안전·접근성
- [ ] 실명·학번·연락처 입력이 없다. 파일 업로드가 없다.
- [ ] 입장 화면에 개인정보 안내 문구가 있다. (10차시는 전 화면 고정 문구)
- [ ] 기본 글자 16px 이상, 누르는 곳 48px 이상이다.
- [ ] 색만으로 뜻을 구분하지 않는다.
- [ ] `prefers-reduced-motion` 을 존중한다.
- [ ] 저작권 표기가 있다.

## 검증
- [ ] `node build/smoke_webapp.js "out/webapp/L<NN>"` 가 OK 를 냈다.
- [ ] `node build/run_webapp.js "out/webapp/L<NN>"` 가 OK 를 냈다.
