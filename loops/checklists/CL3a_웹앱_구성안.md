# CL3a. 웹앱 구성안·프롬프트 완료 정의

작업 : `L<NN>/웹앱 구성안`, `L<NN>/웹앱 프롬프트`
산출 : `out/webapp/L<NN>/SPEC.md`, `out/webapp/L<NN>/PROMPT.md`

**앱보다 프롬프트가 먼저다.** 프롬프트 자체가 산출물이다.
선생님들이 각자 앱을 고쳐 쓸 수 있어야 한다.

## SPEC.md
- [ ] 앱 이름·slug·산출 경로가 `lessons.json` 과 같다.
- [ ] 차시 번호와 학습 문제가 있다.
- [ ] 무엇을 하는 앱인지 한 문단으로 적혀 있다.
- [ ] 화면 목록이 `lessons.json` 의 `webapp.screens` 와 같다.
- [ ] 교사 화면에서 무엇을 보는지 적혀 있다.
- [ ] 저장 형태(payload)가 예시로 있다.
- [ ] 지도 유의점이 빠짐없이 옮겨졌다.
- [ ] 기기가 없을 때 대안이 적혀 있다.

## PROMPT.md
- [ ] 통째로 복사해 붙일 수 있는 코드 블록이 있다.
- [ ] 단일 HTML, 외부 라이브러리·CDN 금지가 명시돼 있다.
- [ ] 방 코드 6자리 + 비밀번호 4자리 + 닉네임 입장이 명시돼 있다.
- [ ] **방 코드 복사 버튼**을 두라는 지시가 있다.
- [ ] **혼자 체험 경로**를 두라는 지시가 있다.
- [ ] **닉네임 중복을 막지 말라**는 지시가 있다.
- [ ] **교사가 나가도 방이 사라지면 안 된다**는 지시가 있다.
- [ ] **정규식에 역슬래시 이스케이프를 쓰지 말라**는 지시가 있다.
- [ ] Firebase 주소·경로와 Sheets 백업(no-cors)이 명시돼 있다.
- [ ] 글자 16px 이상, 터치 44px 이상이 명시돼 있다.
- [ ] 안전 문구 지시가 있다. 10차시는 익명 집계 지시가 추가로 있다.
- [ ] 고쳐 쓰는 법이 적혀 있다.

## 검증
- [ ] `py -3 build/validate_webapp_spec.py "out/webapp/L<NN>"` 가 OK 를 냈다.
