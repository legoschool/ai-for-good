# CL5. 웹사이트 완료 정의

작업 : `L<NN>/사이트 차시 페이지`, `SITE/웹사이트 구현`
산출 : `out/site/`

## 구조
- [ ] 홈 1, 모듈 3, 차시 12, 웹앱 모음 1, 진단 1, 소개 1 = 19쪽이 있다.
- [ ] 모든 페이지에 같은 머리말 메뉴가 있다.
- [ ] 현재 페이지가 메뉴에서 표시된다.

## 페이지마다
- [ ] `<html lang="ko">` 와 viewport 메타가 있다.
- [ ] `<title>` 이 비어 있지 않고 페이지마다 다르다.
- [ ] 끊긴 링크가 없다.
- [ ] 외부 CDN·폰트를 참조하지 않는다.
- [ ] 저작권 표기가 바닥글에 있다.
- [ ] 가로 스크롤이 생기지 않는다. 표는 자체 스크롤 상자에 있다.

## 차시 페이지
- [ ] 학습 문제가 있다.
- [ ] 중점 휴먼스킬 표(지식·이해 / 과정·기능 / 가치·태도)가 있다.
- [ ] 도입·전개·정리 흐름이 발문과 예상 답변까지 있다.
- [ ] 지도안·활동지·PPT 내려받기 링크가 실제 파일을 가리킨다.
- [ ] 웹앱 열기와 제작 프롬프트 링크가 있다.
- [ ] AI 미사용 대안과 지도 유의점이 있다.
- [ ] 앞 차시·다음 차시 이동이 있다.
- [ ] 다른 차시 내용이 섞여 있지 않다.

## 검증
- [ ] `node build/check_site.js out/site` 가 OK 를 냈다.
- [ ] 산출물을 다시 만든 뒤 `make_site.py` 도 다시 돌렸다.
