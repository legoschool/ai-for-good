# CL6. 진도표·교구·해설서 완료 정의

## 학교자율시간 진도표 (XLSX)
- [ ] 시트 4개 : 진도표, 시수 배분, 평가 계획, 사전사후 설문.
- [ ] 진도표에 12차시가 모두 있고 첫 행이 고정돼 있다.
- [ ] 시수 합계가 13이다. 실과 6 + 도덕 2 + 국어 1 + 자율 4.
- [ ] 학교자율시간·창의적 체험활동이 **4차시(7·8·10·12)** 로 적혀 있다. 3차시가 아니다.
- [ ] 평가 계획이 중점 7역량 전부다.
- [ ] 설문 시트에 변화량 자동 계산 수식과 역채점 안내가 있다.
- [ ] `py -3 build/validate_xlsx.py` 가 OK 를 냈다.

## 카드 교구 3종 (HWPX)
- [ ] 정보 분류 카드 24장(4차시), AI 활용 장면 카드 12장(5차시), 상황 카드 20장(6차시).
- [ ] 자르는 선이 카드마다 있다.
- [ ] 몇 칸으로 나누는지 첫 장에 적혀 있다.
- [ ] 웹앱 없이도 같은 활동을 할 수 있다고 적혀 있다.
- [ ] `py -3 build/validate_hwpx.py` 가 OK 를 냈다.

## 교사용 해설서 (HWPX)
- [ ] 프로그램 개관, 모듈 구성, 4색 신호등, 약속 8조항 뿌리가 있다.
- [ ] 차시별 지도 유의점 12차시가 모두 있다.
- [ ] 부적정 활용 신호와 대응이 있다.
- [ ] 도구 준비 안내가 있다.
- [ ] 평가 기준(상·중·하)이 중점 7역량 전부 있다.
- [ ] 자주 묻는 질문이 있다.
- [ ] `py -3 build/validate_hwpx.py` 가 OK 를 냈다.
