# 3차시 웹앱 구성안 : 편향 관찰 갤러리

- 차시 : 3차시 AI도 편견을 가질까
- 학습 문제 : AI의 결과에 담긴 치우침을 찾고, 그 까닭을 데이터에서 찾아봅시다.
- slug : `bias-gallery`
- 산출 경로 : `out/webapp/L03/index.html`

## 무엇을 하는 앱인가

교사가 올린 편향 사례를 학생이 관찰하고, 치우친 지점과 그 원인을 데이터와 연결해 기록한다.

## 화면

1. 사례 관찰 화면
2. 치우친 지점 표시
3. 원인 설명 문장 쓰기
4. 누가 불편해질까 모으기

## 교사 화면

사례별 학생 설명 문장을 모아 학급 화면으로 띄우기

## 공통 사양 (12개 앱이 같다)

`spec/07_웹앱_공통사양.md` 를 그대로 따른다.

- 방 코드 6자리 + 비밀번호 4자리 + 닉네임 입장, 혼자 체험 경로, 교사 대시보드
- Firebase 실시간 DB `/wise/bias-gallery/<방코드>/` + Google Sheets 백업
- Google Sites 소스 코드 삽입용 단일 HTML. 외부 CDN 참조 없음
- 실명·학번·연락처를 수집하지 않는다

## 저장하는 것

```json
{ "nick": "닉네임", "group": "모둠", "app": "bias-gallery",
  "room": "방코드", "at": 0, "payload": { } }
```

## 지도 유의점

- 학생이 직접 이미지 생성 도구를 다루지 않는다. 교사 시연으로 한다.
- 특정 성별·직업·나라를 비하하는 표현이 나오지 않게 사전 확인한다.
- 결과를 비웃는 분위기가 되지 않게 한다.

## 기기가 없을 때

생성형 도구를 쓰지 않고, 교사가 미리 준비한 편향 사례 인쇄 카드로 동일한 관찰·설명 활동을 한다.
