# 6차시 웹앱 구성안 : AI 신호등 판정단

- 차시 : 6차시 AI 신호등 판단 놀이
- 학습 문제 : AI를 써도 되는 상황을 네 가지 신호로 나누어 판단해 봅시다.
- slug : `signal-judges`
- 산출 경로 : `out/webapp/L06/index.html`

## 무엇을 하는 앱인가

상황 카드 20장을 4색 신호로 분류하고 학급 집계를 실시간으로 띄워, 의견이 갈린 카드를 다시 토의한다.

## 화면

1. 상황 카드 4색 분류
2. 근거 한 줄 쓰기
3. 학급 실시간 집계
4. 갈린 카드 재토의 화면

## 교사 화면

카드별 4색 분포 막대와 의견이 가장 갈린 카드 순위

## 공통 사양 (12개 앱이 같다)

`spec/07_웹앱_공통사양.md` 를 그대로 따른다.

- 방 코드 6자리 + 비밀번호 4자리 + 닉네임 입장, 혼자 체험 경로, 교사 대시보드
- Firebase 실시간 DB `/wise/signal-judges/<방코드>/` + Google Sheets 백업
- Google Sites 소스 코드 삽입용 단일 HTML. 외부 CDN 참조 없음
- 실명·학번·연락처를 수집하지 않는다

## 13개 앱이 함께 갖춘 기능

- **발표 모드** : 교사 화면의 `결과 크게 띄우기` 를 누르면 학급 화면용 큰 글씨로 결과만 보여 준다
- **자동 임시 저장** : 쓰던 내용을 이 기기에 8초마다 저장한다. 인터넷이 끊겨도 사라지지 않는다
- **진행 막대** : 활동이 몇 단계 중 어디까지 왔는지 상단에 표시한다
- **개인 되돌아보기** : 학생 화면에서만 보이는 요약을 준다. 교사 화면에는 학급 집계만 간다
- **교사 화면 낱낱이 보기** : 표를 접었다 펼 수 있고, 모둠 수와 마지막 제출 시각을 함께 보여 준다

## 지도 유의점

- 정답을 미리 알려주지 않고 근거로 설득하게 한다.
- 결과를 사진으로 남겨 7차시에 활용한다.

## 기기가 없을 때

인쇄 상황 카드와 4색 분류판으로 진행하고, 학급 집계는 칠판에 스티커를 붙여 대신한다.
