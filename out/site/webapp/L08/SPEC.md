# 8차시 웹앱 구성안 : 약속 선포 게시판

- 차시 : 8차시 우리 반 AI 약속 선포식
- 학습 문제 : 우리 반 AI 약속을 다른 사람에게 알릴 자료를 만들어 봅시다.
- slug : `pledge-board`
- 산출 경로 : `out/webapp/L08/index.html`

## 무엇을 하는 앱인가

모둠이 만든 캠페인 자료의 제목·문구·AI 활용 표기를 글로 등록하고, 교사 승인 뒤 학급에 공개한다.

## 화면

1. 역할 분담표 입력
2. 캠페인 문구 등록
3. AI 활용 표기표 작성
4. 교사 승인 후 게시판

## 교사 화면

게시 승인·반려, 활용 표기 누락 확인

## 이 앱만의 규칙

이미지 업로드 기능은 두지 않는다. 실물 자료는 인쇄물과 교사 화면 공유로 나눈다.

## 공통 사양 (12개 앱이 같다)

`spec/07_웹앱_공통사양.md` 를 그대로 따른다.

- 방 코드 6자리 + 비밀번호 4자리 + 닉네임 입장, 혼자 체험 경로, 교사 대시보드
- Firebase 실시간 DB `/wise/pledge-board/<방코드>/` + Google Sheets 백업
- Google Sites 소스 코드 삽입용 단일 HTML. 외부 CDN 참조 없음
- 실명·학번·연락처를 수집하지 않는다

## 13개 앱이 함께 갖춘 기능

- **발표 모드** : 교사 화면의 `결과 크게 띄우기` 를 누르면 학급 화면용 큰 글씨로 결과만 보여 준다
- **자동 임시 저장** : 쓰던 내용을 이 기기에 8초마다 저장한다. 인터넷이 끊겨도 사라지지 않는다
- **진행 막대** : 활동이 몇 단계 중 어디까지 왔는지 상단에 표시한다
- **개인 되돌아보기** : 학생 화면에서만 보이는 요약을 준다. 교사 화면에는 학급 집계만 간다
- **교사 화면 낱낱이 보기** : 표를 접었다 펼 수 있고, 모둠 수와 마지막 제출 시각을 함께 보여 준다

## 지도 유의점

- 학생 얼굴·이름이 드러나는 자료는 올리지 않는다.
- 생성형 이미지 도구는 교사 계정으로만 쓴다.
- 게시판은 교사 승인 후 공개한다.

## 기기가 없을 때

기기가 부족하면 손그림 포스터로 제작하고, 활용 표기표만 웹앱에 등록한다.
