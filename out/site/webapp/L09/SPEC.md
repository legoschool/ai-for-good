# 9차시 웹앱 구성안 : 3단계 글쓰기 기록판

- 차시 : 9차시 생각을 먼저, AI는 그다음
- 학습 문제 : 내 생각을 먼저 쓰고 AI의 도움을 받아 글을 다듬어 봅시다.
- slug : `three-step-writing`
- 산출 경로 : `out/webapp/L09/index.html`

## 무엇을 하는 앱인가

내 생각 먼저, AI 검토, 내 말로 재구성의 세 글을 한 화면에 나란히 저장하고 무엇이 달라졌는지 쓴다.

## 화면

1. 1단계 내 생각 쓰기
2. 2단계 AI가 짚어 준 점 기록
3. 3단계 내 말로 다시 쓰기
4. 세 글 나란히 비교

## 교사 화면

학생별 3단계 완료 여부와 변화 설명 문장

## 이 앱만의 규칙

1단계를 저장하기 전에는 2단계 입력창이 열리지 않는다.

## 공통 사양 (12개 앱이 같다)

`spec/07_웹앱_공통사양.md` 를 그대로 따른다.

- 방 코드 6자리 + 비밀번호 4자리 + 닉네임 입장, 혼자 체험 경로, 교사 대시보드
- Firebase 실시간 DB `/wise/three-step-writing/<방코드>/` + Google Sheets 백업
- Google Sites 소스 코드 삽입용 단일 HTML. 외부 CDN 참조 없음
- 실명·학번·연락처를 수집하지 않는다

## 13개 앱이 함께 갖춘 기능

- **발표 모드** : 교사 화면의 `결과 크게 띄우기` 를 누르면 학급 화면용 큰 글씨로 결과만 보여 준다
- **자동 임시 저장** : 쓰던 내용을 이 기기에 8초마다 저장한다. 인터넷이 끊겨도 사라지지 않는다
- **진행 막대** : 활동이 몇 단계 중 어디까지 왔는지 상단에 표시한다
- **개인 되돌아보기** : 학생 화면에서만 보이는 요약을 준다. 교사 화면에는 학급 집계만 간다
- **교사 화면 한 명씩 보기** : 표를 접었다 펼 수 있고, 모둠 수와 마지막 제출 시각을 함께 보여 준다

## 지도 유의점

- 2단계에서 ‘대신 써 줘’ 요청이 나오면 즉시 되짚는다.
- 1단계를 건너뛰고 AI부터 쓰지 않게 한다.

## 기기가 없을 때

기기가 없는 모둠은 교사 시연 결과를 함께 검토하고 종이 활동지에 3단계를 기록한다.
