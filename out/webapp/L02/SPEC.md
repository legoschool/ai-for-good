# 2차시 웹앱 구성안 : AI 검증 실험실

- 차시 : 2차시 AI도 틀린다, 환각과 검증
- 학습 문제 : AI의 답이 정말 맞는지 확인하는 방법을 찾아봅시다.
- slug : `verify-lab`
- 산출 경로 : `out/webapp/L02/index.html`

## 무엇을 하는 앱인가

같은 질문에 대한 두 도구의 답을 나란히 기록하고, 검증 3단계를 따라가며 환각 사례 카드를 만든다.

## 화면

1. 질문·답 나란히 기록
2. 검증 3단계 체크
3. 환각 사례 카드 작성
4. 학급 사례 모음

## 교사 화면

학급이 찾은 환각 사례를 한눈에 모아 보기

## 공통 사양 (12개 앱이 같다)

`spec/07_웹앱_공통사양.md` 를 그대로 따른다.

- 방 코드 6자리 + 비밀번호 4자리 + 닉네임 입장, 혼자 체험 경로, 교사 대시보드
- Firebase 실시간 DB `/wise/verify-lab/<방코드>/` + Google Sheets 백업
- Google Sites 소스 코드 삽입용 단일 HTML. 외부 CDN 참조 없음
- 실명·학번·연락처를 수집하지 않는다

## 지도 유의점

- 사실 확인이 가능한 질문으로만 한정한다.
- 개인 이름을 넣어 검색하지 않는다.
- 특정 서비스 비방으로 흐르지 않게 한다.

기기가 없으면 교사가 미리 뽑아 둔 AI 답변 인쇄물 두 장을 모둠에 배부해 대조하게 한다.
