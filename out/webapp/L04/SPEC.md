# 4차시 웹앱 구성안 : 정보 분류 카드

- 차시 : 4차시 내 정보는 안전할까
- 학습 문제 : AI에 넣어도 되는 정보와 넣으면 안 되는 정보를 가려 봅시다.
- slug : `info-sorter`
- 산출 경로 : `out/webapp/L04/index.html`

## 무엇을 하는 앱인가

정보 카드 24장을 입력 가능·조건부·입력 금지로 끌어다 놓고, 근거를 적어 학급 결과와 비교한다.

## 화면

1. 카드 3칸 분류판
2. 근거 쓰기
3. 학급 집계 비교
4. 개인정보 지킴이 수칙 만들기

## 교사 화면

카드별 학급 분류 분포와 의견이 갈린 카드 확인

## 공통 사양 (12개 앱이 같다)

`spec/07_웹앱_공통사양.md` 를 그대로 따른다.

- 방 코드 6자리 + 비밀번호 4자리 + 닉네임 입장, 혼자 체험 경로, 교사 대시보드
- Firebase 실시간 DB `/wise/info-sorter/<방코드>/` + Google Sheets 백업
- Google Sites 소스 코드 삽입용 단일 HTML. 외부 CDN 참조 없음
- 실명·학번·연락처를 수집하지 않는다

## 13개 앱이 함께 갖춘 기능

- **발표 모드** : 교사 화면의 `결과 크게 띄우기` 를 누르면 학급 화면용 큰 글씨로 결과만 보여 준다
- **자동 임시 저장** : 쓰던 내용을 이 기기에 8초마다 저장한다. 인터넷이 끊겨도 사라지지 않는다
- **진행 막대** : 활동이 몇 단계 중 어디까지 왔는지 상단에 표시한다
- **개인 되돌아보기** : 학생 화면에서만 보이는 요약을 준다. 교사 화면에는 학급 집계만 간다
- **교사 화면 한 명씩 보기** : 표를 접었다 펼 수 있고, 모둠 수와 마지막 제출 시각을 함께 보여 준다

## 지도 유의점

- 실제 개인정보를 활동 중에 입력하지 않는다.
- 특정 학생의 실제 사례를 예로 들지 않는다.
- 서비스별 사용 가능 연령을 함께 확인한다.
