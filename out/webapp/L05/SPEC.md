# 5차시 웹앱 구성안 : 보조·대행 분류판

- 차시 : 5차시 보조자일까, 대행자일까
- 학습 문제 : AI가 나를 도와주는 순간과 나를 대신하는 순간을 구분해 봅시다.
- slug : `helper-or-doer`
- 산출 경로 : `out/webapp/L05/index.html`

## 무엇을 하는 앱인가

AI 활용 장면 12개를 보조와 대행으로 분류하고, 모둠 사이에 갈린 장면을 학급 화면에서 다시 토의한다.

## 화면

1. 장면 카드 2칸 분류
2. 근거 한 줄 쓰기
3. 학급 집계와 갈린 카드
4. 사람이 할 일 목록 모으기

## 교사 화면

장면별 보조·대행 비율과 의견이 갈린 장면 표시

## 공통 사양 (12개 앱이 같다)

`spec/07_웹앱_공통사양.md` 를 그대로 따른다.

- 방 코드 6자리 + 비밀번호 4자리 + 닉네임 입장, 혼자 체험 경로, 교사 대시보드
- Firebase 실시간 DB `/wise/helper-or-doer/<방코드>/` + Google Sheets 백업
- Google Sites 소스 코드 삽입용 단일 HTML. 외부 CDN 참조 없음
- 실명·학번·연락처를 수집하지 않는다

## 저장하는 것

{ "nick": "닉네임", "group": "모둠", "app": "helper-or-doer",
  "room": "방코드", "at": 0, "payload": { } }

## 지도 유의점

- 정답 맞히기가 아니라 근거 말하기에 초점을 둔다.
- 자기 경험을 밝히기 어려워하는 학생은 카드로만 참여하게 허용한다.
- 솔직하게 말한 학생을 지지해 준다.

## 기기가 없을 때

인쇄 장면 카드와 모둠 분류판만으로 진행하고, 학급 집계는 칠판 스티커로 대신한다.
