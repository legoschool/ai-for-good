# 10차시 웹앱 구성안 : 사용 습관 자가 점검

- 차시 : 10차시 AI에 기대도 괜찮을까
- 학습 문제 : 나의 AI 사용 습관을 점검하고 디지털 웰빙 약속을 정해 봅시다.
- slug : `habit-check`
- 산출 경로 : `out/webapp/L10/index.html`

## 무엇을 하는 앱인가

일주일 사용 습관을 익명으로 점검하고 학급 평균만 보여 주며, 디지털 웰빙 약속 3가지를 정한다.

## 화면

1. 일주일 사용 기록 체크
2. 보조·대행 비율 자동 계산
3. AI가 못 하는 일 모으기
4. 내 디지털 웰빙 약속 3가지

## 교사 화면

학급 익명 집계만 표시. 개별 응답을 볼 수 있는 화면을 만들지 않는다.

## 이 앱만의 규칙

모든 화면 하단에 ‘힘든 마음은 믿을 수 있는 어른에게 먼저 말해요’ 안내 문구를 고정한다.

## 공통 사양 (12개 앱이 같다)

`spec/07_웹앱_공통사양.md` 를 그대로 따른다.

- 방 코드 6자리 + 비밀번호 4자리 + 닉네임 입장, 혼자 체험 경로, 교사 대시보드
- Firebase 실시간 DB `/wise/habit-check/<방코드>/` + Google Sheets 백업
- Google Sites 소스 코드 삽입용 단일 HTML. 외부 CDN 참조 없음
- 실명·학번·연락처를 수집하지 않는다

## 13개 앱이 함께 갖춘 기능

- **발표 모드** : 교사 화면의 `결과 크게 띄우기` 를 누르면 학급 화면용 큰 글씨로 결과만 보여 준다
- **자동 임시 저장** : 쓰던 내용을 이 기기에 8초마다 저장한다. 인터넷이 끊겨도 사라지지 않는다
- **진행 막대** : 활동이 몇 단계 중 어디까지 왔는지 상단에 표시한다
- **개인 되돌아보기** : 학생 화면에서만 보이는 요약을 준다. 교사 화면에는 학급 집계만 간다
- **교사 화면 낱낱이 보기** : 표를 접었다 펼 수 있고, 모둠 수와 마지막 제출 시각을 함께 보여 준다

## 지도 유의점

- 응답은 익명으로 처리하고 개인 결과를 공개하지 않는다.
- 사용량이 많은 학생을 지적하는 분위기가 되지 않게 한다.
- 정서적 어려움이 드러나면 수업 후 개별 면담으로 연결한다.
- 위험 신호를 개인별로 표시하는 화면을 만들지 않는다.

## 기기가 없을 때

종이 자가 점검표로 진행하고, 학급 집계는 손 들기로 익명 집계한다.
