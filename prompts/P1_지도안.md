# P1. 교수·학습 지도안

작업 : `L<NN>/지도안`
산출 : `out/지도안/WISE_L<NN>_지도안.hwpx`
규격 : `CLAUDE.md` 3-1절, `spec/04_산출물_규격.md` A절
생성 : `build/make_lesson_hwpx.py <차시번호>`

---

## 무엇을 만드는가

차시 하나의 교수·학습 지도안 HWPX 다.

- **원본을 복사해 제자리 수정한다.** 빈 상태에서 새로 조립하면 한글이 보안 경고를 띄운다.
- 표지 문단 10개 + 해당 차시 문단 4개만 남기고 나머지 차시를 지운다.
- 표지를 이 차시 전용으로 바꾼다. 모듈·차시·학습 문제를 넣는다.
- 고친 문단의 `linesegarray` 를 지운다. 안 지우면 글자가 겹쳐 보인다.
- 옛 표기(웹앱1·2·3)를 이 차시의 실제 웹앱 이름으로 바꾼다.
- 도입 5분 · 전개 30분 · 정리 5분 구조와 표를 그대로 둔다.
- 교사 발문마다 예상 답변이 있어야 한다.
- 부호 `☆` 교사 준비물 · `★` 학생 배부물·웹앱 · `△` 지도 유의점 을 유지한다.

## 만드는 법

```bash
build/make_lesson_hwpx.py <차시번호>
```

이 스크립트가 `data/lessons.json` 하나에서 산출물을 만든다.
**산출물을 직접 고치지 않는다.** 내용을 바꾸려면 `lessons.json` 을 고치고 다시 만든다.
규칙이 바뀌면 이 문서와 스크립트를 함께 고친다.

## 끝났는지 어떻게 아는가

`loops/checklists/CL1_지도안.md` 를 한 항목씩 실제로 확인하며 채운다.
그다음 `next_task.py` 가 알려 준 자동 검증 명령을 실행한다.
