# P2. 수업용 PPT

작업 : `L<NN>/PPT`
산출 : `out/ppt/WISE_L<NN>_수업.pptx`
규격 : `CLAUDE.md` 3-4절, `spec/04_산출물_규격.md` C절
생성 : `build/make_ppt.py <차시번호>`

---

## 무엇을 만드는가

차시 하나의 수업용 PPTX 다. 교사가 화면에 띄우고 수업한다.

- 16:9 (13.333in × 7.5in), 10~16장.
- 폰트를 `맑은 고딕` 으로 **명시적으로 지정한다.** 지정하지 않으면 교사 PC에서 깨진다.
- 순서 : 표지 / 학습문제 / 동기유발 / 전개 활동 n개 / 웹앱 / 대안 / 정리 / 오늘의 배움
- **발표자 노트에 교사 발문과 예상 답변을 그대로 넣는다.**
  이것이 지도안과 PPT를 잇는 고리다. 빈 노트가 하나도 없어야 한다.
- 슬라이드 본문은 요약이다. 지도안 문장을 통째로 붙이지 않는다.
- 모듈 색을 띠와 강조에 쓴다. 모듈1 파랑 · 모듈2 주황 · 모듈3 초록.
- 밝은 배경으로 만든다. 교실 프로젝터에서 어두운 화면은 보이지 않는다.

## 만드는 법

```bash
build/make_ppt.py <차시번호>
```

이 스크립트가 `data/lessons.json` 하나에서 산출물을 만든다.
**산출물을 직접 고치지 않는다.** 내용을 바꾸려면 `lessons.json` 을 고치고 다시 만든다.
규칙이 바뀌면 이 문서와 스크립트를 함께 고친다.

## 끝났는지 어떻게 아는가
