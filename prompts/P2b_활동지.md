# P2b. 학생 활동지

작업 : `L<NN>/활동지`
산출 : `out/활동지/WISE_L<NN>_활동지.hwpx`
규격 : `CLAUDE.md` 3-1절, `spec/04_산출물_규격.md` B절
생성 : `build/make_worksheet_hwpx.py <차시번호>`

---

## 무엇을 만드는가

차시 하나의 학생 활동지 HWPX 다. 인쇄해서 나눠 준다.

- **표를 쓰지 않는다.** 원본의 단순 문단만 복제한다.
  표를 복제하면 셀 참조가 어긋나 한글이 보안 경고를 띄운다.
- 항목은 `lessons.json` 의 `worksheet.sections` 를 그대로 쓴다.
- 항목마다 쓸 수 있는 줄을 4줄 둔다.
- 이름칸은 학교·학년·반·모둠·닉네임이다. **실명 칸을 두지 않는다.**
- 자기점검 문항 4개를 넣는다. 델파이 원칙의 학습자용 확인문항을 학생 언어로 옮긴 것이다.
- 이 차시 웹앱 이름과 방 코드를 적을 칸을 둔다.
- AI 미사용 대안 활동을 적는다.
- 한 문장 40자 이내, 초등 5·6학년이 읽는 낱말만 쓴다.

## 만드는 법

```bash
build/make_worksheet_hwpx.py <차시번호>
```

이 스크립트가 `data/lessons.json` 하나에서 산출물을 만든다.
**산출물을 직접 고치지 않는다.** 내용을 바꾸려면 `lessons.json` 을 고치고 다시 만든다.
규칙이 바뀌면 이 문서와 스크립트를 함께 고친다.

## 끝났는지 어떻게 아는가

`loops/checklists/CL2_활동지.md` 를 한 항목씩 실제로 확인하며 채운다.
그다음 `next_task.py` 가 알려 준 자동 검증 명령을 실행한다.
