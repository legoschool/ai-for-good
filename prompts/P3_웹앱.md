작업 : `L<NN>/웹앱 구현`

---

## 무엇을 만드는가

Google Sites 소스 코드 삽입용 **단일 HTML 파일**이다. Apps Script 웹앱이 아니다.

12개 앱이 공통 골격(`build/webapp_core.py`)을 쓰고 활동 화면만 다르다.
활동 화면은 5종이다 (`build/webapp_activities.py`).

| 종류 | 쓰는 차시 |
|---|---|
| `buckets` 카드 분류 | 4 · 5 · 6 |
| `form` 단계별 기록 | 1 · 2 · 3 · 9 · 11 · 12 |
| `vote` 제안과 투표 | 7 |
| `board` 승인 게시판 | 8 |
| `selfcheck` 익명 자가 점검 | 10 |

### 절대 어기지 않는 것

- 외부 CDN·웹폰트를 참조하지 않는다. 학교망에서 차단된다.
- 정규식에 `\d` `\s` `\w` 를 쓰지 않는다. Apps Script 가 역슬래시를 파괴한다.
- 방 코드 복사 버튼, 혼자 체험 경로, 교사 대시보드를 반드시 둔다.
- 닉네임 중복을 막지 않는다. 교사가 나가도 방이 사라지지 않는다.
- 실명·학번·연락처를 묻지 않는다. 파일 업로드를 만들지 않는다.
- Firebase 는 REST 로 직접 호출한다. SDK 를 인라인하지 않는다. 3초 폴링을 쓴다.
- Sheets 백업은 `no-cors` + `text/plain` 이고, 실패해도 학생 화면을 막지 않는다.
- 10차시는 익명 집계만 보여 주고 안전 문구를 전 화면에 고정한다.

## 만드는 법

```bash
build/make_webapp.py <차시번호>
```

이 스크립트가 `data/lessons.json` 하나에서 산출물을 만든다.
**산출물을 직접 고치지 않는다.** 내용을 바꾸려면 `lessons.json` 을 고치고 다시 만든다.
규칙이 바뀌면 이 문서와 스크립트를 함께 고친다.

## 끝났는지 어떻게 아는가

`loops/checklists/CL3_웹앱.md` 를 한 항목씩 실제로 확인하며 채운다.
그다음 `next_task.py` 가 알려 준 자동 검증 명령을 실행한다.
