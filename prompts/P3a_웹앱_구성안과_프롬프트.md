규격 : `spec/07_웹앱_공통사양.md` 전체
생성 : `build/make_webapp.py <차시번호>`

---

## 무엇을 만드는가

**앱보다 프롬프트가 먼저다.** SPEC.md(구성안) → PROMPT.md(완성 프롬프트) → index.html 순서로 만든다.

프롬프트 자체가 산출물이다. 선생님들이 각자 앱을 고쳐 쓸 수 있어야 한다.

### SPEC.md 는 무엇을 담는가

- 앱 이름·slug·경로, 차시와 학습 문제
- 무엇을 하는 앱인지 한 문단
- 화면 목록 (`lessons.json` 의 `webapp.screens`)
- 교사 화면에서 무엇을 보는지
- 저장 형태(payload) 예시
- 지도 유의점과 기기가 없을 때 대안

### PROMPT.md 는 무엇을 담는가

통째로 복사해 AI 도구에 붙일 수 있는 코드 블록 하나다. 그 안에
수업 맥락, 화면, 반드시 지킬 것 11가지, 저장 방식, 안전 문구, 말투 규칙이 들어간다.
`spec/09_웹앱_결함목록.md` 의 10건이 '반드시 지킬 것' 의 뿌리다.

## 만드는 법

```bash
build/make_webapp.py <차시번호>
```

이 스크립트가 `data/lessons.json` 하나에서 산출물을 만든다.
**산출물을 직접 고치지 않는다.** 내용을 바꾸려면 `lessons.json` 을 고치고 다시 만든다.
규칙이 바뀌면 이 문서와 스크립트를 함께 고친다.

## 끝났는지 어떻게 아는가

`loops/checklists/CL3a_웹앱_구성안.md` 를 한 항목씩 실제로 확인하며 채운다.
그다음 `next_task.py` 가 알려 준 자동 검증 명령을 실행한다.
