# P4. 웹사이트 디자인 시안

작업 : `SITE/웹사이트 디자인 시안` · 산출 : `out/site/design/`

이 작업만 **Claude Design** 에 맡긴다. 아래 블록을 붙여 넣는다.

---

```
초등 교사가 쓰는 수업자료 사이트의 디자인 시안을 만들어 줘.

[사이트]
이름 : 인간중심 사고를 기르는 AI적정활용 수업 WISE
대상 : 초등 5·6학년 담임 교사
성격 : 12차시 수업 꾸러미를 내려받고 웹앱을 여는 자료실

[페이지]
홈 / 모듈 3쪽 / 차시 12쪽 / 12차시 웹앱 모음 / 자기인식 진단 / 소개

[차시 페이지에 들어갈 것]
1. 모듈 띠와 차시 표시
2. 학습 주제와 학습 문제
3. 자료 내려받기 (지도안 · 활동지 · PPT · 웹앱 열기 · 제작 프롬프트)
4. 휴먼스킬 표
5. 수업 흐름 (도입 · 전개 · 정리)
6. 오늘 쓰는 웹앱
7. 기기가 없어도 함께합니다
8. 지도 유의점
9. 교육과정 표
10. 앞 차시 / 다음 차시

[색]
모듈1 발견 #2563eb · 모듈2 판단 #d97706 · 모듈3 실천 #059669
브랜드 #1d4ed8 · 바탕 #f9fafb · 종이 #ffffff
신호등 초록 #16a34a 노랑 #eab308 주황 #f97316 빨강 #dc2626

[지켜야 할 것]
- 외부 웹폰트를 쓰지 마라. 학교망에서 차단된다.
- 밝은 배경 하나로 통일해라. 다크 모드를 만들지 마라.
  교실 프로젝터에서 어두운 화면은 보이지 않는다.
- 본문 17px 이상, 누르는 곳 48px 이상.
- 색만으로 뜻을 구분하지 마라.
- 가로 스크롤이 생기면 안 된다.
- 교사가 가장 먼저 찾는 것은 자료 내려받기다. 위쪽에 둬라.
- em dash 를 쓰지 마라.

[내가 원하는 것]
홈과 차시 페이지의 시안, 그리고 색·글자·간격·버튼 값을 정리한 표.
```

---

시안이 나오면 `out/site/design/` 에 저장하고 상태를 완료로 바꾼 뒤,
`spec/05_디자인_시스템.md` 를 갱신하고 `prompts/P5_웹사이트_구현.md` 로 넘긴다.

```bash
py -3 build/update_state.py "SITE/웹사이트 디자인 시안" 완료 "시안 확정"
```
