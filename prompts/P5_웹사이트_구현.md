# P5. 웹사이트 구현

작업 : `L<NN>/사이트 차시 페이지, SITE/웹사이트 구현`
산출 : `out/site/`
규격 : `spec/05_디자인_시스템.md`, `spec/08_사이트_구조.md`
생성 : `build/make_site.py`

---

## 무엇을 만드는가

빌드 도구 없이 열리는 **독립 정적 사이트**다.

- 19쪽이다. 홈 1 · 모듈 3 · 차시 12 · 웹앱 모음 1 · 진단 1 · 소개 1.
- 내용은 `data/lessons.json` 에서만 가져온다. 페이지에 직접 쓰지 않는다.
- 스타일은 `assets/style.css` 한 곳에 둔다.
- 외부 CDN·웹폰트를 참조하지 않는다.
- 모든 링크가 실제 파일을 가리켜야 한다. 끊긴 링크가 없어야 한다.
- 산출물을 `out/site/files/` 와 `out/site/webapp/` 으로 복사한다.
  **다른 것을 다시 만들었으면 사이트도 다시 만든다.**
- 모든 페이지 바닥글에 티처스랩 저작권 표기를 유지한다.

미리보기용 단일 파일이 필요하면 :

```bash
py -3 build/preview_page.py lesson/L06.html out/preview.html
```

## 만드는 법

```bash
py -3 build/make_site.py
```

이 스크립트가 `data/lessons.json` 하나에서 산출물을 만든다.
**산출물을 직접 고치지 않는다.** 내용을 바꾸려면 `lessons.json` 을 고치고 다시 만든다.
규칙이 바뀌면 이 문서와 스크립트를 함께 고친다.

## 끝났는지 어떻게 아는가

`loops/checklists/CL5_사이트.md` 를 한 항목씩 실제로 확인하며 채운다.
그다음 `next_task.py` 가 알려 준 자동 검증 명령을 실행한다.
