전체가 끝난 뒤 마지막으로 돌린다.

---

## 1. 자동 검증 전부

```bash
py -3 build/verify_all.py
```

80개 검사가 전부 OK 여야 한다. 하나라도 NG 면 여기서 멈춘다.

## 2. 사람이 확인할 것

자동으로 잡을 수 없는 것이다.

### 한글 파일
- [ ] 지도안 12편을 한글에서 연다. **보안 경고가 뜨지 않는다.**
- [ ] 표 안 글자가 겹쳐 보이지 않는다.
- [ ] 활동지를 인쇄했을 때 쓸 자리가 충분하다.
- [ ] 카드 교구를 인쇄해 자를 수 있다.

### PPT
- [ ] 교사 PC에서 폰트가 깨지지 않는다.
- [ ] 프로젝터에서 뒷자리 학생이 읽을 수 있다.
- [ ] 발표자 노트가 발표자 보기에서 보인다.

### 웹앱
- [ ] 방을 만들고 코드를 복사해 다른 기기로 들어가 본다.
- [ ] **교사 화면을 닫았다가 다시 열어도 방이 살아 있다.**
- [ ] 같은 닉네임으로 다시 들어가면 기록이 이어진다.
- [ ] 인터넷을 끊고 제출해도 학생 화면이 멈추지 않는다.
- [ ] 태블릿에서 가로 스크롤이 생기지 않는다.
- [ ] Google Sites 소스 코드 삽입에 붙여 넣고 동작한다.
- [ ] Firebase 에 기록이 쌓이고 Sheets 에도 같은 행이 들어간다.

### 사이트
- [ ] 홈에서 12차시까지 클릭만으로 갈 수 있다.
- [ ] 자료 내려받기가 실제로 내려받아진다.
- [ ] 휴대폰에서 메뉴가 겹치지 않는다.

## 3. 교육과정 확인

- [ ] 12차시 학습 주제가 계획서와 같다.
- [ ] 신호등이 **4단계**다. 3단계 표현이 남아 있지 않다.
- [ ] 학교자율시간이 **4차시**다.
- [ ] 중점 휴먼스킬 7개가 평가 기준에 연결돼 있다.
- [ ] AI적정활용 8가지 구성요소가 약속 8조항에 대응한다.

## 4. 안전 확인

- [ ] 어떤 화면에도 실명·학번·연락처 입력이 없다.
- [ ] 10차시 앱이 개인 응답을 보여 주지 않는다.
- [ ] 8차시 게시판이 교사 승인 뒤에만 공개된다.
- [ ] 공개 배포물에 델파이 원문이나 공유 금지 자료가 들어가지 않았다.

## 5. 배포 준비

- [ ] Apps Script 를 백업 시트에 붙이고 웹 앱으로 배포했다.
- [ ] 배포 URL 을 `build/make_webapp.py` 의 `SHEET_ENDPOINT` 에 넣고 다시 만들었다.
- [ ] Firebase 보안 규칙을 넣었다.
- [ ] `out/site/` 를 정적 호스팅에 올렸다.
