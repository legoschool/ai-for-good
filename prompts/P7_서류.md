# P7. 진도표·카드 교구·교사용 해설서

작업 : `공통/학교자율시간 진도표, 공통/카드 교구 3종, 공통/교사용 해설서`
산출 : `out/서류/, out/교구/, out/해설서/`
규격 : `spec/04_산출물_규격.md` D·E·F절
생성 : `build/make_docs.py <진도표|교구|해설서|all>`

---

## 무엇을 만드는가

세 가지를 만든다.

**진도표 (XLSX)** : 시트 4개. 진도표 12차시, 시수 배분(합계 13), 평가 계획(중점 7역량),
사전사후 설문(변화량 자동 계산 수식).
학교자율시간·창의적 체험활동은 **4차시(7·8·10·12)** 다. 계획서의 3차시는 오기다.

**카드 교구 (HWPX 3종)** : 정보 분류 카드 24장(4차시), AI 활용 장면 카드 12장(5차시),
상황 카드 20장(6차시). 자르는 선을 카드마다 두고, 웹앱 없이도 같은 활동을 할 수 있다고 적는다.

**교사용 해설서 (HWPX)** : 9개 절. 개관, 모듈, 4색 신호등, 약속 8조항의 뿌리,
차시별 지도 유의점 12차시, 부적정 활용 신호와 대응, 도구 준비, 평가, 자주 묻는 질문.

## 만드는 법

```bash
build/make_docs.py <진도표|교구|해설서|all>
```

이 스크립트가 `data/lessons.json` 하나에서 산출물을 만든다.
**산출물을 직접 고치지 않는다.** 내용을 바꾸려면 `lessons.json` 을 고치고 다시 만든다.
규칙이 바뀌면 이 문서와 스크립트를 함께 고친다.
