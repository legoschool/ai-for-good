# spec/04. 산출물 규격

## A. 교수·학습 지도안 (HWPX 12편)

경로 : `out/지도안/WISE_L<NN>_지도안.hwpx`

- `assets/base_지도안.hwpx` 를 복사해 **제자리 수정**한다. 새로 조립하지 않는다.
- 표지 문단 10개 + 해당 차시 문단 4개만 남긴다.
- 차시 문단 구성 : 제목 / 모듈·학습문제 / 표 / 빈 문단
- 표 안에 휴먼스킬 표와 도입·전개·정리 표가 들어 있다. 표 구조를 건드리지 않는다.
- 표지는 이 차시 전용으로 바꾼다. 모듈·차시·학습 문제를 넣는다.
- 부호 : `☆` 교사 준비물 · `★` 학생 배부물·웹앱 · `△` 지도 유의점

## B. 학생 활동지 (HWPX 12종)

경로 : `out/활동지/WISE_L<NN>_활동지.hwpx`

- **표를 쓰지 않는다.** 원본의 단순 문단만 복제한다. 표를 복제하면 셀 참조가 어긋난다.
- 구성 : 제목 / 차시·학습문제 / 이름칸 / 활동 항목 / 자기점검 / 웹앱 방코드 / 대안 / 저작권
- 활동 항목은 `lessons.json` 의 `worksheet.sections` 를 그대로 쓴다.
- 항목마다 쓸 수 있는 줄을 4줄 둔다.
- 이름칸은 학교·학년·반·모둠·닉네임이다. **실명 칸을 두지 않는다.**

## C. 수업용 PPT (PPTX 12세트)

경로 : `out/ppt/WISE_L<NN>_수업.pptx`

- 16:9 (13.333in × 7.5in), 10~16장.
- 폰트는 `맑은 고딕` 을 명시적으로 지정한다.
- 슬라이드 순서 : 표지 / 학습문제 / 동기유발 / 전개 활동 n개 / 웹앱 / 대안 / 정리 / 오늘의 배움
- **발표자 노트에 교사 발문과 예상 답변을 그대로 넣는다.** 이것이 지도안과 PPT를 잇는 고리다.
- 슬라이드 본문은 요약이다. 지도안 문장을 통째로 붙이지 않는다.
- 모듈 색 : 모듈1 `#2563eb` · 모듈2 `#d97706` · 모듈3 `#059669`

## D. 학교자율시간 진도표 (XLSX 1종)
