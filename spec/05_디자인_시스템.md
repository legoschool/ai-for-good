# spec/05. 디자인 시스템

웹앱 12개와 통합 사이트가 같은 얼굴을 하도록 값을 한곳에 모았다.

## 색

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 잉크 | `#111827` | 제목 |
| 본문 | `#374151` | 본문 |
| 흐림 | `#6b7280` | 보조 설명 |
| 선 | `#e5e7eb` | 테두리 |
| 종이 | `#ffffff` | 카드 배경 |
| 바탕 | `#f9fafb` | 페이지 배경 |
| 브랜드 | `#1d4ed8` | 링크, 강조 |
| 모듈1 | `#2563eb` | 발견 |
| 모듈2 | `#d97706` | 판단 |
| 모듈3 | `#059669` | 실천 |

신호등 색은 `data/lessons.json` 의 `signals[].color` 를 쓴다.
초록 `#16a34a` · 노랑 `#eab308` · 주황 `#f97316` · 빨강 `#dc2626`

**색만으로 뜻을 구분하지 않는다.** 신호등은 색과 글자를 함께 쓴다.

## 글자

```css
font-family: "Pretendard","Malgun Gothic","맑은 고딕",system-ui,sans-serif;
```

- 웹앱 본문 19px, 모바일 18px, 학생 입력 20px
  (2026-08-18 교실 검토에서 글자가 작다는 지적을 받아 16px → 19px 로 올렸다.
  카드 제목 24px, 표와 보조 설명 17px, 상단바 15px.)
- 사이트 본문 17px, 모바일 16px
- 줄 간격 1.7
- 제목은 700, 강조는 800

**웹폰트를 내려받지 않는다.** 학교망에서 차단되고 로딩이 느리다.

## 간격과 모양

- 모서리 : 카드 16px, 버튼·입력 10~11px, 알약 999px
- 카드 안 여백 : 사이트 24~26px, 웹앱 18px
- 최대 폭 : 사이트 1080px, 웹앱 1000px

## 누르는 것

- 최소 크기 48px × 48px (실제 값은 버튼·선택지 52px, 상단바 44px)
- 기본 버튼은 채움, 보조는 테두리(`ghost`), 소극적인 것은 회색(`plain`)
- 비활성은 투명도 0.45

## 화면 크기

```css
@media (max-width:640px) { /* 본문 18px, 여백 축소, 메뉴 줄바꿈 */ }
```

- 교사는 노트북, 학생은 태블릿으로 본다.
- **가로 스크롤이 생기면 안 된다.** 넓은 표는 `overflow-x:auto` 상자 안에서만 스크롤한다.

## 명암

- **밝은 배경 하나로 통일한다.** 다크 모드를 만들지 않는다.
  교실 프로젝터에서 어두운 화면은 보이지 않는다.

## 움직임

```css
@media (prefers-reduced-motion:reduce) { *{transition:none!important;animation:none!important} }
```
