# spec/08. 통합 웹사이트 구조

**독립 정적 사이트**로 만든다. 빌드 도구 없이 열리는 순수 HTML/CSS/JS다.

## 참고한 선례

「바이브코딩으로 만나는 사회정서교육」(박창민 외 7명, 광문각) 사이트에서
영역 → 세부 → 차시의 계층 구조와 차시 페이지 구성을 가져왔다.
그 사이트는 32차시 전부에 지도안·활동지·웹앱·PPT를 갖춘 완성 사례다.

우리는 12차시 3모듈이므로 계층을 한 단계 줄였다.

## 페이지 지도

```
out/site/
├─ index.html                 홈
├─ apps.html                  12차시 웹앱 모음
├─ survey.html                AI적정활용 자기인식 진단
├─ about.html                 프로그램 소개
├─ module/
│   ├─ M1.html                모듈1 WISE 발견 (1~4차시)
│   ├─ M2.html                모듈2 WISE 판단 (5~8차시)
│   └─ M3.html                모듈3 WISE 실천 (9~12차시)
├─ lesson/
│   └─ L01.html ~ L12.html    차시 페이지 12쪽
├─ assets/style.css           공통 스타일
├─ files/                     지도안·활동지·PPT 36개
└─ webapp/                    웹앱 12개 + 공통 설문
```

## 머리말 메뉴

홈 · 모듈1 발견 · 모듈2 판단 · 모듈3 실천 · 12차시 웹앱 · 자기인식 진단 · 소개

현재 페이지는 `aria-current="page"` 로 표시한다.

## 홈 구성

1. 표지 : 프로그램 이름, 핵심 질문, 요약 알약 4개
2. 세 개의 모듈 : 모듈 카드 3장
3. 함께 쓰는 자료 : 웹앱 모음 · 진단 · 소개 카드 3장
4. AI 신호등 : 4색 띠
5. 12차시 한눈에 보기 : 차시 목록 12줄

## 차시 페이지 구성

순서를 지킨다.

1. 모듈 띠와 차시 표시
2. 학습 주제와 학습 문제
3. **자료 내려받기** (지도안 · 활동지 · PPT · 웹앱 열기 · 제작 프롬프트)
4. 휴먼스킬 표 (지식·이해 / 과정·기능 / 가치·태도)
5. 수업 흐름 (도입 · 전개 · 정리, 발문과 예상 답변까지)
6. 오늘 쓰는 웹앱
7. 기기가 없어도 함께합니다
8. 지도 유의점 + AI적정활용 연계
9. 교육과정 (성취기준 · 교과시수 · 산출물 · 평가)
10. 앞 차시 / 다음 차시 이동

**자료 내려받기를 위로 올린다.** 선생님이 가장 먼저 찾는 것이다.

## 지켜야 할 것

- 외부 CDN·웹폰트를 참조하지 않는다. 학교망에서 차단된다.
- 모든 페이지 바닥글에 티처스랩 저작권 표기를 유지한다.
- 반응형이어야 한다. 교사는 노트북, 학생은 태블릿으로 본다.
- 가로 스크롤이 생기면 안 된다.
- `data/lessons.json` 에서만 내용을 가져온다. 페이지에 직접 쓰지 않는다.

## 배포

`out/site/` 를 통째로 정적 호스팅에 올린다.
경로가 전부 상대 경로이므로 하위 폴더에 올려도 동작한다.
