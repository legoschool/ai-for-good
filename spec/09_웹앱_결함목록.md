# spec/09. 웹앱 결함 목록

「바이브코딩으로 만나는 사회정서교육」 32차시 웹앱을 실제로 교실에서 돌리며
터졌던 결함이다. **모델이 매번 다시 발견하기 어려우므로 체크리스트에 박아 두었다.**

`build/smoke_webapp.js` 가 이 중 자동으로 잡을 수 있는 것을 검사한다.

| # | 터진 것 | 왜 터졌나 | 막는 법 |
|---|---|---|---|
| 1 | 방 코드를 복사할 수 없다 | 복사 버튼이 없고 학생이 6자리를 눈으로 옮겨 적다 틀린다 | 복사 버튼을 둔다. `navigator.clipboard` 실패 시 `textarea` 대체 경로를 둔다 |
| 2 | 교사가 나가면 방이 사라진다 | 방 상태를 브라우저 메모리에 두었다 | 방 정보를 서버 `meta` 에 쓴다. 교사 화면은 조회만 한다 |
| 3 | 닉네임 중복으로 재입장이 막힌다 | 중복 검사를 넣었다 | 중복을 막지 않는다. 같은 닉네임이면 기존 기록을 이어받는다 |
| 4 | 학교망에서 화면이 비어 있다 | CDN 스크립트가 차단됐다 | 외부 참조를 전부 없앤다. 단일 HTML 로 만든다 |
| 5 | Apps Script 로 옮기니 정규식이 깨진다 | `Index.html` 의 역슬래시가 파괴된다 | `\d` `\s` `\w` 를 쓰지 않는다. `[0-9]` 등 문자 클래스로 쓴다 |
| 6 | 실시간 갱신이 자꾸 끊긴다 | SSE 스트리밍이 학교망 프록시에서 끊긴다 | 3초 폴링으로 바꾼다 |
| 7 | 제출 버튼을 눌러도 아무 일이 없다 | 검증 실패를 조용히 삼켰다 | 무엇이 빠졌는지 화면에 알려 준다 |
| 8 | 인터넷이 끊기면 학생 화면이 멈춘다 | 저장 실패를 처리하지 않았다 | 로컬에 먼저 저장하고 안내 문구를 띄운다. 백업은 대기열에 쌓는다 |
| 9 | 태블릿에서 표가 화면 밖으로 나간다 | 표에 최소 폭을 주고 감싸지 않았다 | `overflow-x:auto` 상자로 감싼다. body 는 가로 스크롤되지 않게 한다 |
| 10 | 프로젝터에서 글씨가 안 보인다 | 다크 모드와 작은 글자를 썼다 | 밝은 배경 하나로 통일한다. 본문 16px 이상, 누르는 곳 48px 이상 |

## 자동으로 잡는 것

`node build/smoke_webapp.js <폴더>` 가 1·3·4·5·9·10 을 잡는다.
`node build/run_webapp.js <폴더>` 가 7 을 잡는다. DOM 을 흉내 내 실제로 실행한다.

2·6·8 은 스크립트로 잡기 어렵다. 체크리스트에서 사람이 확인한다.
