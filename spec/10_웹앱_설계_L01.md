# spec/10. 1차시 웹앱 설계 : 데이터 실험실

> 코드보다 먼저 정한다. 이 문서가 통과되어야 만들기 시작한다.
> 기준은 「바이브코딩으로 만나는 사회정서교육」 웹앱이다. 화면 하나짜리 폼이 아니라
> 학생이 주인공인 사건이어야 한다.

---

## 1. 이 앱이 만들어야 하는 단 하나의 경험

**학생이 AI의 선생님이 된다.**

1. 내가 붙인 이름표대로 AI가 배운다.
2. 내가 가르친 만큼만 맞힌다.
3. 내가 한쪽을 굶기면 AI가 무너진다.

이 세 가지를 말로 듣는 것이 아니라 **직접 저질러서** 겪게 한다.
그래서 마지막 발문 "AI를 똑똑하게 만든 것은 누구일까요"에 학생이 자기 경험으로 답한다.

무엇을 하지 않을 것인가도 정한다.

- 정답 맞히기 게임으로 만들지 않는다. 라벨에는 정답이 없다. 사람이 정하는 것이다.
- 점수로 줄 세우지 않는다. 점수는 AI의 정확도이지 학생의 실력이 아니다.
- 외부 AI 서비스를 부르지 않는다. 분류기는 브라우저 안에서 돈다.

---

## 2. 세계관

**AI 학교.** 학생은 선생님이고, 갓 태어난 AI 학생 **몽이**를 가르친다.

- 몽이는 아무것도 모른다. 머릿속이 빈 공책이다.
- 카드 그림은 **진짜 사진**이다. 사람은 사진을 보고 이름표를 붙인다.
- 몽이는 **사진을 보지 못한다.** 카드에 적힌 네 가지 특징만 본다. 귀 모양, 꼬리 길이, 몸집, 털 색.
  (사람이 보는 것과 기계가 보는 것이 다르다는 점이 이 차시의 첫 번째 장면이다.)
- 몽이는 배운 것만 안다. 배우지 못한 것은 자신 없게 찍는다.

말투는 짧고 순하다. 몽이는 자기가 왜 그렇게 답했는지 항상 밝힌다.
"귀가 뾰족해서 고양이 쪽으로 기울었어요. 62%예요."

40분을 다섯 교시로 나눈다. 허브에서 언제든 오갈 수 있다.

|---|---|---|
| 1교시 | 2교시로 가기 | 카드 3장을 다 판단해야 나온다 |
| 2교시 | 3교시로 가기 | 이름표 6장 미만이면 안내만 띄우고 멈춘다. 20장이 안 되면 몇 장 남았는지 알린다 |
| 3교시 | 4교시로 가기 | 학습과 시험을 마쳐야 넘어간다 |
| 4교시 | 5교시로 가기 | 없음 |
| 5교시 | 몽이 성적표 보기 | 없음 |

모든 화면에 '교무실로' 버튼도 그대로 둔다.

### 기다리는 시간 (2026-08-18 추가)

계산은 브라우저 안에서 순식간에 끝난다. 그대로 두면 누른 순간 결과가 튀어나와
"몽이가 무엇을 했는지"가 보이지 않는다. 그래서 일부러 기다리는 시간을 만든다.

| 언제 | 얼마 | 무엇을 보여 주나 |
|---|---|---|
| 3교시 학습 | 1.3초 | 도는 표시 + "몽이가 카드를 한 장씩 보는 중이에요" + 카드 수만큼 차오르는 막대. 버튼은 잠긴다 |
| 3교시 시험 | 0.9초 | 도는 표시 + 뼈대 세 줄 → 결과 카드가 한 장씩 0.1초 간격으로 올라옴 |
| 4교시 편식 재학습 | 1.1초 | 도는 표시 + "카드를 빼고 처음부터 다시 배우는 중이에요" |
| 2교시 카드 넘김 | 0.3초 | 사진이 스르르 바뀜 |
| 우리 반 기록 | 실제 대기 | 도는 표시 + 뼈대 두 줄 |

**움직임을 줄이도록 설정한 기기에서는 기다리지 않는다.** 0초로 지나간다.

## 4. 화면별 설계

### S3. 1교시 나라면 어떻게 맞힐까

AI를 켜기 전에 사람의 판단을 먼저 꺼내 놓는다.

- 카드 3장을 한 장씩 크게 보여 주고 강아지·고양이를 고르게 한다.
- 고른 뒤 **무엇을 보고 정했는지** 특징 네 개 중에서 고르게 한다.
- 세 장을 마치면 학급에서 많이 고른 근거를 보여 준다. 정답 판정은 하지 않는다.
- 마무리 한 줄 : "여러분이 방금 쓴 그 기준을, 이제 몽이에게 가르칩니다."

### S4. 2교시 이름표 붙이기

- 카드 20장. 한 번에 한 장, 화면 절반을 차지하는 큰 그림.
- 버튼 두 개(강아지·이름표 / 고양이·이름표). 누르면 다음 카드로 자동으로 넘어간다.
- 왼쪽 위에 **배움 상자**가 카드 수만큼 차오른다. 20장을 채우면 상자가 닫힌다.
- 되돌리기 버튼을 둔다. 이름표는 언제든 바꿀 수 있어야 한다.
- 다 붙이면 : "우리 반이 이 카드에 붙인 이름표"를 보여 준다. 같은 카드에 다르게 붙은 카드를 표시한다.
  라벨이 갈리는 경험이 3차시 편향으로 이어진다.

### S5. 3교시 학습시키고 시험 보기

- **학습 버튼** : 누르면 1.5초 동안 학습 애니메이션(공책이 채워지는 그림)이 돌고 끝난다.
  실제로 그 사이에 나이브 베이즈가 학생의 라벨로 학습한다.
- **시험** : 시험 카드 6장을 몽이가 한 장씩 푼다. 맞으면 초록, 틀리면 빨강.
- **몽이의 머릿속** : 카드마다 특징 네 개가 어느 쪽으로 얼마나 기울었는지 막대로 보여 준다.
  "귀 뾰족 → 고양이 92% / 꼬리 길다 → 고양이 55% / 몸집 작다 → 고양이 71% / 털 어둡다 → 강아지 52%"
- 정확도를 큰 숫자로 보여 주고, 학급 평균과 나란히 놓는다.
- 발문 카드 : "몽이는 무엇을 보고 판단했나요? 여러분이 1교시에 쓴 기준과 같나요?"

### 카드 더미 설계 원칙 (실측으로 정한 것)

처음 만든 카드 더미는 손으로 그린 그림에 특징 네 개를 적어 둔 것이었다.
2026-08-18 검토에서 "진짜 사진을 써야 한다"는 요구를 받아 **사진 26장으로 다시 만들었다.**

사진은 Openverse 에서 **CC0 · 퍼블릭 도메인** 인 것만 골랐다. 다른 이용 허락(CC BY, CC BY-SA)은
쓰지 않는다. 이 자료가 CC BY-NC-SA 라서 조건이 어긋난다.
사진은 파일로 두지 않고 260×195 로 줄여 HTML 안에 data URI 로 넣는다.
학교망에서 바깥을 부르지 않기 위해서다. 26장 합쳐 242KB, 앱 전체는 400KB 다.

**특징은 사진을 보고 적는다.** 사진에 꼬리가 보이지 않으면 그 사진은 쓰지 않았다.
그래서 코 색이 빠지고 **털 색(밝다·어둡다)** 이 들어왔다. 코는 작게 찍힌 사진이 많고,
털 색은 강아지와 고양이 양쪽에 고르게 퍼져 있어 "하나로 갈리지 않는" 조건을 만든다.

조건은 셋이다.

- 어느 특징 하나로도 완전히 갈리지 않는다. 귀만 보고 가르치면 몇 장은 틀린다.
  (귀 처짐인 고양이 = 스코티시폴드 2장, 귀 뾰족인 강아지 = 셰퍼드·코기·스피츠·핀셔 등 6장)
- 시험 카드 여섯 장 중 두 장은 특징이 서로 어긋난다. 데이터가 줄면 이 카드부터 틀린다.
- 고양이 카드를 8 → 6 → 4 → 2장으로 줄이면 정확도가 계단처럼 내려간다.

사진대로 붙인 학생은 100점에서 33점까지 내려간다. 편식 실험이 눈에 보인다.
귀만 보고 붙인 학생은 처음부터 83점이고, 데이터를 줄여도 83점 그대로다.
**이 두 줄이 서로 다른 것이 수업 재료다.** 편식이 무너뜨리는 것은
"제대로 가르친 몽이"이지, 처음부터 대충 가르친 몽이가 아니다.
"왜 어떤 모둠은 점수가 안 떨어졌을까"를 물으면 라벨 이야기로 이어진다.

카드를 바꾸려면 이 표를 다시 재고 이 문서를 갱신한다.
잴 때는 앱을 열어 20장을 붙이고 3교시·4교시를 실제로 눌러 본다.

굶길 대상은 학생이 더 많이 붙인 이름표 쪽으로 자동으로 정한다. 그래야 실제로 무너진다.

### S6. 4교시 편식 실험

- 슬라이더 하나 : **고양이 카드를 몇 장만 남길까요** (10장 → 2장).
- 다시 학습 버튼. 같은 시험지를 다시 푼다.
- 결과를 **두 줄 막대**로 나란히 보여 준다. 전체 학습 82% / 편식 학습 50%.
- 틀린 카드만 모아 보여 준다. 대부분 고양이다.
- 발문 카드 : "왜 고양이를 자주 틀리게 되었을까요?"
- 한 줄 쓰기 : "데이터를 줄였더니 ___ 되었습니다."

### S7. 5교시 사람이 한 일과 AI가 한 일

- 오늘 실제로 있었던 일 10가지를 카드로 준다.
  (어떤 카드를 모을지 정했다 / 이름표를 붙였다 / 규칙을 계산했다 / 정확도를 계산했다 …)
- 사람 칸과 AI 칸으로 나눈다. 정답 판정을 즉시 하지 않는다.
- 다 나누면 학급 분포를 보여 주고, 갈린 항목을 함께 이야기한다.
- 마지막 한 줄 : "몽이를 똑똑하게 만든 것은 ___ 입니다."

### S8. 성적표

- 몽이 성적표 카드를 그림으로 만든다. 닉네임, 이름표 20장, 정확도 전체·편식, 배움 문장.
- **PNG로 저장**해서 활동지에 붙이거나 교실에 걸 수 있다.
- 배지 : 이름표 스무 장(성실한 선생님), 편식 실험 완료(실험가), 배움 문장 작성(생각 기록자).
- 다음 차시 예고 한 줄 : "몽이는 배운 대로만 답해요. 다음 시간에는 몽이가 지어낸 말을 잡아 봅니다."

## 7. 활동지·PPT와의 연결

앱 화면과 종이가 1:1로 맞물린다. 앱을 못 쓰는 학급도 같은 흐름을 종이로 간다.

| 활동지 칸 | 앱 화면 | 무엇을 옮겨 적나 |
|---|---|---|
| 1. 우리 모둠이 모은 데이터 | S4 | 이름표 20장 중 강아지 몇 장, 고양이 몇 장 |
| 2. 라벨 붙이기 | S4 학급 비교 | 우리 반에서 갈린 카드 한 장과 내 이유 |
| 3. 데이터를 줄였더니 | S6 | 전체 정확도와 편식 정확도, 자주 틀린 카드 |
| 4. 사람이 한 일과 AI가 한 일 | S7 | 사람 칸 · AI 칸 목록과 배움 문장 |

PPT는 이 다섯 교시를 그대로 따라간다. 슬라이드마다 앱 화면 이름과 교사 발문을 넣는다.
교사는 화면 왼쪽에 앱, 오른쪽에 PPT를 띄우지 않아도 된다. **PPT가 앱을 설명하지 않고, 앱이 수업이다.**

## 8. 기기가 부족할 때

- 모둠에 한 대 : 이름표는 모둠이 함께 정하고 한 사람이 입력한다. 나머지는 활동지에 같이 적는다.
- 한 대도 없을 때 : 인쇄 카드 20장에 이름표 스티커를 붙이고, 교사 화면 한 대로 학습·시험을 시연한다.
  편식 실험은 교사가 고양이 카드를 빼고 다시 시연한다.

## 9. 접근성과 안전

- 버튼 최소 48px, 본문 16px 이상, 색만으로 뜻을 구분하지 않는다(색 + 글자).
- 학습 애니메이션은 `prefers-reduced-motion` 을 존중해 즉시 결과로 넘어간다.
- 단일 HTML, 외부 참조 없음. 학교망과 구글 사이트 삽입에서 그대로 돈다.
- 정확도는 몽이의 성적이지 학생의 성적이 아니라고 화면에 적는다.

- [ ] 혼자 체험 경로가 끝까지 막히지 않는다
