# spec/18. 9차시 웹앱 설계 : 3단계 글쓰기 기록판

> 코드보다 먼저 정한다. 이 문서가 통과되어야 만들기 시작한다.
> 번호는 `9 + 차시` 규칙을 따른다. 10번이 1차시, 12번이 3차시, 18번이 9차시다.
> 색과 조각은 새로 만들지 않는다. **인수인계서 8절 디자인 규격을 그대로 쓴다.**
> 벗어나는 것은 9절에 따로 적었다.

---

## 1. 이 앱이 만들어야 하는 단 하나의 경험

**학생이 AI에게 던지는 말을 바꾸는 것.**

"대신 써 줘"가 아니라 "무엇이 부족한지 짚어 줘"로 바꾸는 순간이 이 차시의 전부다.

1. 빈 종이 앞에서 **AI를 켜지 못한다.** 내 생각 다섯 문장을 먼저 써야 자물쇠가 열린다.
2. 질문을 만든다. "대신 써 줘"라고 쓰면 화면이 곧바로 되짚는다.
3. AI가 짚어 준 것을 **한 줄씩 나눠 놓고 받아들일 것과 아닌 것을 고른다.**
4. 다시 쓴다. 처음 글에서 그대로 남은 낱말이 몇 %인지 화면이 보여 준다.

마지막 발문 "이 글은 누구의 글인가요"에 학생이 자기 기록으로 답한다.

무엇을 하지 않을 것인가도 정한다.

- **앱이 AI를 부르지 않는다.** 진짜 AI는 교사 계정이나 모둠 공용 기기에서 쓴다.
  앱은 그 과정을 기록하고 순서를 지키게 하는 작업실이다.
- 글을 채점하지 않는다. 겹침 비율은 성적이 아니라 되돌아보는 자료다.
- 3단계 글을 AI 문장으로 채우게 두지 않는다. 화면이 겹침을 보여 주고 되묻는다.
- 친구 이름과 사진, 친구 이야기를 쓰지 않게 안내를 고정한다.

## 2. 세계관과 캐릭터

**글 공방.** 학생은 **작가**다. 공방에는 자물쇠가 세 개 달린 문이 있다.

- 첫째 자물쇠는 **내 생각 다섯 문장**으로 열린다.
- 둘째 자물쇠는 **짚어 달라는 질문**으로 열린다. 대신 써 달라는 말로는 열리지 않는다.
- 셋째 자물쇠는 **내 말로 다시 쓴 글**로 열린다.

AI는 공방에 들르는 **조언가**다. 조언가는 글을 대신 쓰지 않는다. 짚어만 준다.
받아들일지 말지는 작가가 정한다. 말투는 짧고 순하다.

## 3. 화면 지도

40분을 여섯 칸으로 나눈다. 공방(허브)에서 언제든 오갈 수 있다.

| # | 화면 | 학생이 하는 일 | 화면에 보이는 것 | 분 |
|---|---|---|---|---|
| S0 | 입장 | 방 코드·닉네임, 또는 둘러보기 | 차시 그림, 개인정보 안내, 사전·사후 설문 안내 | - |
| S1 | 이야기 | 읽고 시작 누르기 | 자물쇠 세 개가 달린 공방 문 | 2 |
| S2 | 공방(허브) | 할 일 고르기 | 타일 6개, 자물쇠 표시, 진행, 배지 | - |
| S3 | 주제 고르기 | 오늘 쓸 주제를 고른다 | 주제 카드 4장, 자유 주제 칸 | 3 |
| S4 | 1단계 초고 | 내 생각 다섯 문장 쓰기 | 문장 수 세기, 자물쇠 열림 표시 | 12 |
| S5 | 질문 만들기 | 짚어 달라는 질문 고르기와 짓기 | 질문 카드 5장, 다듬기 놀이 3문제, 되짚기 | 6 |
| S6 | 2단계 기록 | AI가 짚어 준 것을 줄로 나눠 적고 고르기 | 줄마다 받아들임·보류 단추 | 8 |
| S7 | 3단계 다시 쓰기 | 초고를 옆에 두고 내 말로 다시 쓰기 | 초고 접이식 보기, 겹침 비율 막대 | 8 |
| S8 | 나란히 보기 | 세 글 견주고 달라진 점 쓰기, 카드 저장 | 비교표, 작가 카드 PNG, 학급 평균 | 5 |
| T | 교사 화면 | 방 만들기, 집계, 발표 | 아래 6절 | - |

**자물쇠가 이 앱의 뼈대다.** 잠긴 타일을 누르면 잠긴 까닭을 알려 주고
열어야 하는 화면으로 데려간다. 막기만 하고 두지 않는다.

lessons.json 의 화면 네 개와 이렇게 맞물린다.

| lessons.json 화면 | 이 설계의 화면 |
|---|---|
| 1단계 내 생각 쓰기 | S3 주제 고르기 + S4 1단계 초고 |
| 2단계 AI가 짚어 준 점 기록 | S5 질문 만들기 + S6 2단계 기록 |
| 3단계 내 말로 다시 쓰기 | S7 3단계 다시 쓰기 |
| 세 글 나란히 비교 | S8 나란히 보기 |

## 4. 화면별 설계

### S1. 이야기

- 자물쇠 세 개가 달린 공방 문을 인라인 SVG 로 보여 준다.
- 세 줄로 끝낸다. "빈 종이 앞에서 AI부터 켜면 내 글이 아니게 돼요."
- 우리 반 약속 2조항(내 생각 먼저)을 한 줄로 상기시킨다.
- 단추 하나 : **공방으로 들어가기**

### S3. 주제 고르기

- 주제 카드 4장. 급식 남기기, 우리 반 규칙, 우리 동네에서 고칠 점, 화면 보는 시간.
- 자유 주제 칸을 하나 둔다. 40자까지.
- 주제를 고르면 초고 화면의 안내 문장이 그 주제로 바뀐다.

### S4. 1단계 초고 (첫째 자물쇠)

- 큰 글상자 하나. 맞춤법을 따지지 않는다고 먼저 적는다.
- **문장 수를 실시간으로 센다.** 마침표·물음표·느낌표로 나눈다.
- 다섯 문장을 넘기면 자물쇠가 열린다. `wiseToast` 로 알리고 타일에 열림 표시를 준다.
- 다섯 문장을 못 넘겨도 계속 쓸 수 있다. 막는 것은 다음 단계이지 지금 쓰는 일이 아니다.

### S5. 질문 만들기 (둘째 자물쇠)

- 질문 카드 5장을 고른다. 전부 "짚어 달라"는 말이다.
- **다듬기 놀이 3문제** : 대신 써 달라는 말을 짚어 달라는 말로 바꾸는 고르기 문제다.
  1차시 몸풀기와 같은 자리다. 맞히면 배지를 준다.
- 내 질문 칸에 `대신 써 줘` `완성해 줘` `다시 써 줘` `글 써 줘` 가 들어가면
  곧바로 되짚는다. 어떻게 바꾸면 되는지 예시를 한 줄 보여 준다.
- 질문을 하나 이상 고르거나 지으면 둘째 자물쇠가 열린다.

### S6. 2단계 기록

- AI 답을 통째로 붙이지 않는다. **한 줄에 하나씩** 적게 한다. 최대 다섯 줄.
- 줄마다 단추 두 개 : **받아들일래요 · 안 받아들일래요.** 고르지 않아도 저장은 된다.
- 안 받아들인 줄에는 까닭을 한 줄 적는 칸이 열린다.
- 이 화면을 채우면 셋째 자물쇠가 열린다.

### S7. 3단계 다시 쓰기 (셋째 자물쇠)

- 위쪽에 **초고 접어 보기**를 둔다. 펼치면 1단계 글이 그대로 보인다.
- 아래 큰 글상자에 다시 쓴다.
- **겹침 비율**을 실시간으로 보여 준다. 처음 글에서 그대로 남은 낱말 비율이다.
  - 85% 넘음 : "거의 그대로예요. 짚어 준 것을 반영해 봐요."
  - 15% 못 미침 : "처음 생각이 사라졌어요. 내 주장은 지키고 있나요."
  - 그 사이 : "내 생각을 지키면서 고쳤어요."
- 숫자와 글자를 함께 쓴다. 막대만으로 뜻을 전하지 않는다.

### S8. 나란히 보기

- 표 하나에 세 글의 문장 수와 글자 수, 겹침 비율을 나란히 놓는다.
- 달라진 점 한 줄을 쓴다. 제출에 반드시 필요하다.
- **작가 카드 PNG** : 닉네임, 주제, 문장 수 변화, 겹침 비율, "이 글은 내 글이다".
- **우리 반과 견주기** : 같은 방 학생들의 겹침 비율 평균을 불러온다.
  둘러보기 중에는 안내만 뜬다.
- 배지 : 첫 자물쇠(다섯 문장), 질문 장인(다듬기 3문제), 고쳐 쓴 작가, 되돌아본 작가.

## 5. 저장하는 payload 모양

기존 폼형 앱과 열쇠 이름을 맞춘다. 교사 화면과 활동지 대응이 끊기지 않게 하려는 것이다.

```json
{
  "nick": "닉네임", "group": "모둠", "app": "three-step-writing", "room": "방코드", "at": 0,
  "payload": {
    "topic": "급식 남기기",
    "f0": "1단계 초고 전문",
    "asks": ["내 글에서 근거가 부족한 곳은 어디인가요"],
    "myask": "내 근거 중 약한 것은 무엇인가요",
    "f1": "AI가 짚어 준 점을 줄로 이어 붙인 것",
    "notes": [{ "text": "근거에 자료가 없어요", "take": true, "why": "" }],
    "f2": "받아들일 것과 아닌 것 요약",
    "f3": "3단계 다시 쓴 글",
    "f4": "달라진 점 한 줄",
    "s0": 5, "s3": 6, "len0": 210, "len3": 260, "overlap": 42,
    "quizOk": 3,
    "badges": ["첫 자물쇠", "질문 장인"]
  }
}
```

개인정보는 닉네임뿐이다. 이름·학교·학년·반·전화번호·사진을 받지 않는다.

## 6. 교사 화면과 발표 모드

| 무엇 | 내용 |
|---|---|
| 단계 진행 | 1단계만 · 2단계까지 · 3단계까지 마친 학생 수 |
| 겹침 비율 | 학급 평균과 85% 넘는 글의 수. 넘는 글은 무엇을 반영했는지 물어본다 |
| 질문 갈래 | 다섯 가지 질문 카드의 선택 분포 막대 |
| 되짚은 횟수 | "대신 써 줘"류 질문이 걸린 횟수. 되짚기가 필요한 학급인지 본다 |
| 학생별 표 | 닉네임, 주제, 1단계 문장, 3단계 문장, 겹침, 달라진 점 |
| 발표 모드 | 처음 글과 다시 쓴 글을 세 편까지 크게 나란히 |
| 내려받기 | CSV. 방 잠그기 |

## 7. 활동지·PPT 와의 1:1 연결

| 활동지 칸 | 앱 화면 | 무엇을 옮겨 적나 |
|---|---|---|
| 1단계 내 생각 (5문장) | S4 | 초고 다섯 문장 |
| 2단계 AI가 짚어 준 점 | S6 | 줄로 나눈 기록 |
| 받아들일 것 / 받아들이지 않을 것 | S6 | 줄마다 고른 것과 까닭 |
| 3단계 내 말로 다시 쓰기 | S7, S8 | 다시 쓴 글과 달라진 점 |

PPT 는 이 순서를 그대로 따라간다. **PPT 가 앱을 설명하지 않고, 앱이 수업이다.**

## 8. 기기 없는 대안, 접근성, 안전

- 기기가 없을 때 : 교사 시연 결과를 함께 검토하고 종이 활동지에 3단계를 기록한다.
- 모둠에 한 대 : 초고는 각자 종이에 쓰고, 질문과 기록은 한 사람이 입력한다.
- 진짜 AI 는 교사 계정이나 모둠 공용 기기에서만 연다. 앱은 AI 를 부르지 않는다.
- 누르는 곳 최소 48px, 본문 16px 이상, 넓은 표는 `.scroll` 로 감싼다.
- 색만으로 뜻을 구분하지 않는다. 겹침 막대 옆에 늘 숫자와 글자를 붙인다.
- 잠긴 타일은 색만으로 표시하지 않는다. 자물쇠 그림과 "잠김" 글자를 함께 쓴다.
- 글상자에 친구 이야기와 사람 이름을 쓰지 않도록 안내 상자를 고정한다.
- em dash 를 쓰지 않는다. 외부 참조 0, 단일 HTML.

## 9. 8절 디자인 규격에서 벗어나는 것

- **공방 문 SVG** 는 이 차시에만 쓰는 그림이라 `webapp_l09.py` 안에 둔다.
  `webapp_art.py` 는 13개 앱이 함께 쓰는 그림만 담는다. 3차시도 같은 방식이다.
- 그 밖의 색과 조각은 모듈3 강조색 `#059669` 와 8-2 표를 그대로 쓴다.

## 10. 완료 정의 체크리스트

- [ ] 잠긴 타일을 누르면 까닭을 알려 주고 열어야 할 화면으로 데려간다
- [ ] "대신 써 줘"류 질문이 곧바로 되짚어진다
- [ ] 2단계를 줄로 나눠 적고 줄마다 받아들임을 고를 수 있다
- [ ] 겹침 비율이 실시간으로 보이고 세 구간에서 말이 달라진다

- [ ] 교사 화면에 단계 진행, 겹침 평균, 질문 분포, 되짚은 횟수가 나온다

- [ ] 기다리는 자리마다 스피너와 글자가 있다 (8-6 절)
- [ ] 스모크·실행·골격 동일성·전체 83개 검사 통과, 외부 참조 0, 개인정보 입력 없음
