# spec/19. 10차시 웹앱 설계 : 하루 정비소

> 코드보다 먼저 정한다. 이 문서가 통과되어야 만들기 시작한다.
> 색과 조각은 새로 만들지 않는다. **인수인계서 8절 디자인 규격을 그대로 따른다.**
> 이 차시는 `spec/06_안전_개인정보_규칙.md` 5절이 다른 모든 것보다 우선한다.

---

## 1. 이 앱이 만들어야 하는 단 하나의 경험

**학생이 AI에게 직접 부탁해 보고, 거절당한다.**

1. 내 일주일을 눈으로 본다. 며칠 썼고 무엇에 썼는지가 화면에 남는다.
2. 그 장면을 하나씩 **보조와 대행으로 가른다.** 저울이 내 쪽으로도 AI 쪽으로도 기운다.
3. 로봇 정비사 **또또**에게 열두 가지를 부탁해 본다. 몇 가지는 또또가 못 한다고 답한다.
   "친구와 화해하게 해 줘"에 또또는 "그건 제가 못 해요"라고 답한다.
4. 그래서 마지막 발문 "마음이 많이 힘들 때는 누구에게 말해야 할까요"에
   학생이 자기 경험으로 답한다. 어른에게 말하는 것이 훈계가 아니라 **자기가 찾아낸 답**이 된다.

무엇을 하지 않을 것인가도 정한다.

- **점수로 줄 세우지 않는다.** 사용량이 많은 학생을 나무라는 화면을 만들지 않는다.
  저울은 옳고 그름이 아니라 지금 모습이다.
- **개인 응답을 교사 화면에 띄우지 않는다.** 학급 익명 집계만 남긴다.
- 겁주기로 끝내지 않는다. 마지막은 내가 정한 약속 세 가지다.
- 마음을 묻는 질문을 만들지 않는다. 힘든 마음을 캐묻는 칸을 두지 않는다.
  대신 **어디에 말하면 되는지**를 알려 준다.

## 2. 세계관과 캐릭터

**하루 정비소.** 하루를 마치고 들르는 작은 정비소다. 학생은 자기 일주일을 맡긴다.

- 정비사는 로봇 **또또**다. 부지런하고 솔직하다.
- 또또는 고칠 수 있는 것과 못 고치는 것을 정확히 말한다.
  "그건 제가 못 해요. 사람이 하는 일이에요."
- 또또는 학생의 사용량을 나무라지 않는다. 숫자를 보여 주고 학생이 정하게 한다.

말투는 짧고 담담하다. 놀리지 않고, 겁주지 않는다.

## 3. 화면 지도

40분을 여섯 구역으로 나눈다. 정비소(허브)에서 언제든 오갈 수 있다.

| # | 화면 | 학생이 하는 일 | 화면에 보이는 것 | 분 |
|---|---|---|---|---|
| S0 | 입장 | 방 번호·닉네임, 또는 둘러보기 | 10차시 그림, 익명 안내 | - |
| S1 | 이야기 | 읽고 정비소로 들어가기 | 또또 소개, 익명 약속 | 2 |
| S2 | 정비소(허브) | 구역 고르기 | 타일 6개, 진행 표시, 배지 | - |
| S3 | 기록칸 | 일주일 일곱 칸에 사용량 표시, 쓴 장면 고르기 | 요일 칸, 장면 카드 8장 | 8 |
| S4 | 저울칸 | 고른 장면을 보조와 대행으로 가르기 | 저울 눈금 막대, 비율 숫자 | 8 |
| S5 | 부탁 시험소 | 또또에게 열두 가지를 부탁해 보기 | 또또의 답, 못 하는 일 목록, 사람 카드 | 8 |
| S6 | 약속 작성소 | 디지털 웰빙 약속 3가지 정하기 | 보기 8개 + 직접 쓰기 2칸, 구체성 안내 | 8 |
| S7 | 우리 반(익명) | 학급 집계 보기 | 학급 평균 저울, 못 하는 일 상위 | 4 |
| S8 | 정비 완료증 | 결과 카드 PNG 저장 | 배지, 오늘의 약속 | 2 |
| T | 교사 화면 | 방 만들기, 익명 집계, 발표 | 아래 6절 | - |

**모든 화면 아래에 안전 문구를 고정한다.**
> 힘든 마음은 AI가 아니라 믿을 수 있는 어른에게 먼저 말해요.

## 4. 화면별 설계

### S3. 기록칸

- 월요일부터 일요일까지 일곱 칸. 칸마다 **안 씀 · 조금 · 많이** 세 단계로 누른다.
  숫자를 세게 하지 않는다. 기억나는 대로 고르면 된다.
- 아래에 장면 카드 8장. 이번 주에 해 본 것을 고른다.
  (숙제를 대신 시킴 · 모르는 것 설명 듣기 · 글 다듬기 · 그림 만들기 · 번역 ·
   문제 풀이 답 받기 · 아이디어 받기 · 이야기 상대)
- 다 고르면 한 줄 : "이번 주에 AI를 쓴 날은 X일이에요." 많고 적음을 평가하지 않는다.

### S4. 저울칸

- S3에서 고른 장면만 하나씩 나온다. 두 버튼으로 가른다.
  **보조**(내가 하고 도움만 받음) · **대행**(AI가 대신함)
- 가를 때마다 저울 눈금이 움직인다. 골격의 막대(`barHtml`)를 두 줄로 쓰고 숫자를 함께 적는다.
  새 그림을 만들지 않는다.
  **색만으로 구분하지 않는다.** 글자를 함께 쓴다.
- 다 가르면 비율 한 줄 : "보조 5 · 대행 3 · 대행이 37%예요."
- 발문 카드 : "대행이었던 것 중에 하나만 보조로 바꾼다면 무엇을 바꿀까요?"
  고른 장면 하나를 눌러 두면 약속 작성소에서 문장 후보로 뜬다.

### S5. 부탁 시험소 (이 앱의 심장)

- 또또에게 부탁 카드 12장. 눌러 보면 또또가 답한다. 답은 세 가지다.
  - **할 수 있어요** : 번역, 예시 만들기, 다시 설명하기 등 6장
  - **반만 할 수 있어요** : 사실 확인, 글 다듬기 등 2장. 조건을 함께 말해 준다
  - **그건 제가 못 해요** : 친구와 화해하기, 안아 주기, 진짜로 겪기, 책임지기 등 4장
- 못 한다고 답한 카드는 **못 하는 일 목록**에 쌓인다. 세 개를 모으면 다음이 열린다.
- 다음 : "그럼 이런 일은 누구에게 말할까요" 사람 카드를 고른다.
  가족 · 선생님 · 친구 · 상담 선생님 · 117 학교폭력 신고. 여러 개 고를 수 있다.
- 사람 카드를 하나라도 고르면 안전 문구를 크게 한 번 더 보여 준다.
  이 화면에서만 `.safe` 상자를 크게 쓴다.

### S6. 약속 작성소

- 보기 약속 8개를 준다. 전부 **구체형**이다. "자기 전 30분은 화면을 끈다"처럼 시간과 상황이 있다.
- 셋을 고르거나, 직접 쓰기 두 칸에 내 말로 쓴다. 합쳐서 3개가 되면 작성 완료.
- 직접 쓴 문장에 시간이나 상황을 나타내는 말이 없으면 안내한다. 막지는 않는다.
  "언제, 어떤 때 지킬지 넣어 볼까요. 예: 숙제할 때는 내 생각을 세 줄 먼저 쓴다"
- 저울칸에서 골라 둔 장면이 있으면 문장 후보를 하나 띄운다.

### S7. 우리 반 (익명)

- 방 데이터를 읽어 **학급 평균만** 보여 준다. 닉네임을 화면에 쓰지 않는다.
- 보여 주는 것 : 학급 평균 대행 비율, AI가 못 한다고 본 일 상위 5개, 학급이 많이 고른 약속 5개.
- 화면에 한 줄 고정 : "누가 무엇을 썼는지는 아무에게도 보이지 않아요."
- 둘러보기 중에는 집계가 없다고 알리고 나머지 활동은 그대로 하게 한다.

### S8. 정비 완료증

- 닉네임, 쓴 날 수, 보조와 대행 수, 못 하는 일 하나, 약속 첫 줄을 넣어 PNG로 저장한다.
- 배지 : `일주일 기록` · `저울 맞추기` · `못 하는 일 찾기` · `사람에게 말하기` · `약속 셋`.
- 다음 차시 예고 한 줄 : "다음 시간에는 AI로 우리 마을의 문제를 도와요."

## 5. 저장하는 payload

```json
{
  "nick": "닉네임", "group": "모둠", "app": "habit-check", "room": "방코드", "at": 0,
  "payload": {
    "days": { "0": 1, "1": 2, "2": 0 },
    "scenes": { "0": "agent", "3": "assist" },
    "cant": ["친구와 화해하기", "가족을 안아 주기", "책임지기"],
    "who": ["가족", "선생님"],
    "vows": ["자기 전 30분은 화면을 끈다", "숙제할 때는 내 생각을 세 줄 먼저 쓴다"],
    "usedDays": 4, "assist": 5, "agent": 3, "agentPct": 37,
    "swap": "숙제를 대신 시킴",
    "badges": ["일주일 기록", "약속 셋"]
  }
}
```

마음 상태를 묻는 문항을 두지 않는다. 자유 입력은 약속 두 줄뿐이다.
개인정보는 닉네임뿐이고, 교사 화면은 이 payload 를 **합계로만** 쓴다.

## 6. 교사 화면과 발표 모드

**개인 응답을 절대 띄우지 않는다.** 안전 규칙 5절이 다른 요구보다 우선한다.

| 무엇 | 내용 |
|---|---|
| 제출 인원 | 몇 명이 냈는지만 |
| 학급 저울 | 보조와 대행 합계, 학급 평균 대행 비율 |
| 사용한 날 | 0~7일 분포. 개인을 짚지 않고 막대로만 |
| 못 하는 일 | 학급이 많이 고른 순서 |
| 사람 카드 | 어디에 말하겠다고 했는지 합계 |
| 약속 | 많이 고른 약속 상위. 직접 쓴 문장은 닉네임 없이 모아서 보여 준다 |
| 낱낱이 보기 | **이 차시에서는 끈다.** 골격의 개인 표를 화면에서 감춘다 |
| CSV | 골격이 만든다. 닉네임과 응답이 들어 있으므로 학급 통계만 남기고 지우라는 안내를 화면에 띄운다 |
| 발표 모드 | 학급 평균 저울과 못 하는 일 상위 다섯 개를 큰 글씨로 |

`teacherSummary` 첫 줄에 "개인 응답은 보이지 않습니다"를 고정한다.

## 7. 활동지·PPT 와의 1:1 연결

| 활동지 칸 | 앱 화면 | 무엇을 옮겨 적나 |
|---|---|---|
| 1. 일주일 동안 언제·왜 썼나 | S3 | 쓴 날 수와 고른 장면 |
| 2. 보조였던 것 / 대행이었던 것 | S4 | 두 칸에 장면 이름과 비율 |
| 3. AI가 못 하는 일 | S5 | 또또가 못 한다고 답한 것 세 가지와 말할 사람 |
| 4. 내 디지털 웰빙 약속 3가지 | S6 | 약속 세 줄 |

## 8. 기기 없는 대안, 접근성, 안전

- 종이 자가 점검표로 같은 흐름을 간다. 학급 집계는 손 들기로 익명 집계한다.
- 모둠에 한 대 : 기록칸과 저울칸은 각자 종이에 적고, 부탁 시험소만 함께 눌러 본다.
- 누르는 곳 48px 이상, 본문 16px 이상, 색과 글자를 함께 쓴다.
- 기다림은 `prefers-reduced-motion` 을 존중한다. 8-6절 규격대로 한다.
- **모든 화면에 안전 문구를 고정한다.** 사람 카드 화면에서는 크게 한 번 더 보여 준다.
- 사용량으로 등수를 매기지 않는다. "많이 썼다"는 말을 화면에 쓰지 않는다.

## 9. 완료 정의 체크리스트

- [ ] 화면 여덟 개가 허브에서 오갈 수 있다
- [ ] 일곱 칸을 누르면 쓴 날 수가 바로 따라온다
- [ ] 저울칸에는 S3에서 고른 장면만 나온다
- [ ] 부탁 시험소에서 또또가 못 한다고 답하는 카드가 실제로 있다
- [ ] 못 하는 일 셋을 모아야 사람 카드가 열린다
- [ ] 약속 세 개를 채워야 제출된다
- [ ] 결과 카드가 PNG 로 저장된다
- [ ] 교사 화면에 개인 응답이 없고 낱낱이 보기가 꺼져 있다
- [ ] 모든 화면에 안전 문구가 보인다
- [ ] 둘러보기 경로가 끝까지 막히지 않는다
- [ ] 스모크·실행·골격 동일성·전체 검사 통과, 외부 참조 0
